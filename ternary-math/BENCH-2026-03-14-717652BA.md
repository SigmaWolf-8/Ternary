### Target Methodology

Every performance target is set to the **industry best-in-class** for a comparable algorithm at the **same or lesser security level**. Each category header names the specific standard and citation. All benchmarks use **1024-byte (1KB) standard input** to match NIST, SUPERCOP/eBASH, and liboqs methodology. Industry reference times are from **NIST FIPS reference implementations**; peak optimized assembly implementations may be 2–3× faster on specific hardware. Where the Salvi Framework algorithm exceeds the industry target, the grade reflects how far beyond best-in-class it performs. Where no post-quantum standard exists (e.g., AEAD), the classical best-in-class is used with the security asymmetry noted.
