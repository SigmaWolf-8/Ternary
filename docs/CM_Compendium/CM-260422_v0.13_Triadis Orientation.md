## Appendix C — Extension Convention (How to Add a New Part or Register)

*Future-proofing protocol. Any future agent, reviewer, or co-author proposing new corpus material can use this convention to slot the work into the spine without disturbing existing structure.*

### C.1 — When to add a new Part

Add a new Part (Part XVII, XVIII, …) to Narrative Structure when **all four** of the following hold:

1. **New primary source document** exists with its own version stamp and changelog (not just a section of an existing doc).
2. **New theorem or law** is registered (with a T-number, GRH-suffix, CL-number, or equivalent persistent identifier) — not merely an extended derivation of an existing theorem.
3. **Cross-document role** is non-trivial — the new register is cited by at least two other corpus documents.
4. **Closure boundary** is clear — the Part can carry "Closed" rows in the registry without dragging open items.

If only some of these hold, add the work as a **subsection of an existing Part** (e.g., a new derivation under Part XIV GRH Register) or as a **new corpus row only**, without spine extension.

### C.2 — Where to insert

Insert new Parts at the end of the Registers column (XVI → XVII → …). Do not renumber existing Parts. If a new Part belongs in Foundations or Machinery columns, propose a 0-prefixed sub-number (e.g., Part 0.5, Part IV.5) rather than renumbering.

### C.3 — What to update in the same revision

Every spine extension must update, in the same Triadis revision:

1. **§0.1 Reading Map** — add the new Part to the ASCII diagram.
2. **§0.2 Structural Bridge Objects table** — if the new Part introduces a named bridge (like Triad-364), add it.
3. **Narrative Structure table** — new row with Part number, title, content summary, source citations.
4. **Closed Theorems Registry** — new "From [source document]" subsection listing the closed theorems with status and location.
5. **Document Corpus** — new corpus rows for any newly-cited primary sources.
6. **Appendix B Revision History** — changelog row enumerating every change (numbered list, one item per change).

### C.4 — Naming conventions

- **Part titles**: noun phrase, possibly with kanji / Latin / Greek annotation (matching existing pattern for Parts I–IV).
- **Theorem identifiers**: T-number for general theorems, T-suffix-GRH for GRH-class theorems, CL-number for conservation laws, CP-number for closure principles, T-suffix-other for new theorem classes.
- **Bridge objects**: Two-word name + identity (e.g., "Triad-364 Bridge: 1365/1092 = 5/4").
- **Document filenames**: `[CM|TM|PCO|REF|Cmps]-260422[-NNN]_v[VERSION]_[Title].md` per Capomastro-Holdings stamp standard.

### C.5 — Review gate

A new Part is registered **only after** the underlying theorem(s) have passed UPIID V1.1 review in Nona and graduated from the working weave. Drafts and conjectures stay in `THE-NONA-STATE.md` until closure. This document carries closed material only — no exceptions.
