What is a .plm name?
A .plm name is a human-readable alias bound to a site's 27-trit TDNS address in the PlenumNET registry. It works like a hostname — mysite.plm resolves to the cryptographic address derived from scanning that URL.

Naming rules: The name must be unique. TLDs like .com, .app, and .org are stripped automatically — they have no meaning inside PlenumNET. Only the brand or subdomain label is registered.
