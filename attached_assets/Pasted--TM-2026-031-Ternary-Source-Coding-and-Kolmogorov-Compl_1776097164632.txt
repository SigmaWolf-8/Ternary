## 2. Ternary Entropy over GF(3)

Let a source emit symbols x from 𝒳 = {0, 1, 2} (Rep B) with probabilities p(x). The ternary entropy:

$$H_3(X) = -\sum_{x \in \mathcal{X}} p(x) \log_3 p(x) \quad \text{(trits per symbol)}$$

Related to binary entropy: H₃(X) = H₂(X) / log₂3 = H₂(X) / 1.585

1 trit carries 1.585 bits. A ternary codeword of length ℓ covers 3^ℓ messages vs 2^ℓ for binary. For sources with natural three-fold structure, ternary coding achieves the entropy bound with shorter codewords.

## 3. The Reduced RepD Function (Algebraic Trits)

### 3.1 Definition

The RepD (Repunit Decomposition) of a non-negative integer x is the sequence of remainders when dividing successively by repunits R_n for n = n_max, n_max−1, …, 1.

The **reduced** version outputs algebraic trits instead of ordinary trits {0, 1, 2}.

Define the algebraic trit set:

> **𝒜 = {0, 1, ω}**

where ω is a primitive cube root of unity: ω³ = 1, ω ≠ 1, 1 + ω + ω² = 0.

Multiplication and addition follow the algebra of the Eisenstein integers ℤ[ω].

### 3.2 The Reduced RepD

For a given repunit index n (with R_n known):

> **RepD_alg(x; n) = (q, r_alg)**

where:

1. Perform ordinary integer division: x = q·R_n + r, 0 ≤ r < R_n
2. Reduce the remainder r to an algebraic trit via the canonical map:

> φ(0) = 0, φ(1) = 1, φ(2) = ω

with φ(r) = αr + β in ℤ[ω], where α = (1−ω)/3 and β = (1+2ω)/3.

The quotient q is an ordinary integer (still to be decomposed by smaller repunits). The remainder is an element of ℤ[ω], not an integer.

### 3.3 Example

Decompose x = 14 (= π):

> 14 = 1·R₃ + 1 = 1·13 + 1 → r_alg = φ(1) = 1
> Quotient 1: 1 = 0·R₂ + 1 → r_alg = φ(1) = 1
> Quotient 0: remainder 0 → r_alg = φ(0) = 0

Full algebraic RepD of 14: **[1, 1, 0]** (most significant to least).

### 3.4 Why This Matters

The infimum of entropy H_inf is achieved when as many remainders as possible are zero — because zero is the identity step in the walk, and the orbifold quotient removes it from both step space and position space. The reduced RepD compresses the remainder set from {0, 1, 2} to the group {0, 1, ω} and then applies the dual quotient (Rep C) which removes the identity.
