## Decisions Made (Final)

### Architecture

- **TritInt is Phase 0a.** The ternary/binary gate. No bare integer type holds a trit value or ternary arithmetic result in code above the gate. Binary enters through `TritInt::from_binary()`, exits through `.to_binary()` at the WASM/JS edge.
- **One Trit, four views.** Rep A/B/C/D are not four types — they are four projections of a single value:

```
     Rep A    Rep B    Rep C    Rep D
     (bal)    (std)    (bij)    (alg)

      -1       0        1        0
       0       1        2        1
      +1       2        3        ω
```

- **constants.rs migrates above the gate.** Ternary values stored as TritInt. Not DO-NOT-MODIFY for this task.
- **gf3_algebra.rs is REWRITE, not EXTEND.** 22 pub functions rewritten with Trit types. 12 conversion functions collapse into Trit view methods. 9 tests rewritten — same math, new types.
- **DO-NOT-MODIFY list (7 files, not 8):** gf3.rs, tribonacci.rs, ternary_circle.rs, torus.rs, repunit_circles.rs, tlsponge385.rs, cube_addr.rs. These stay below the gate. Future migration task moves them above incrementally.
