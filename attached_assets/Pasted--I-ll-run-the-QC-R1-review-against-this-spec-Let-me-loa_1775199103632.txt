Recommendation: Do not implement the "conditionally skip" path. The RTL files must exist and be linted. If the files genuinely don't exist yet, the workflow should be disabled (removed or set to workflow_dispatch only) rather than silently skipping. The spec should take a clear position: either the files exist and must be linted, or the workflow is premature and should be gated.
Verification: Confirm the workflow either runs the lint successfully or is explicitly disabled. No if: hashFiles(...) conditional skip pattern should be present for security-critical RTL.

The spec does not define what "reasonable time" means in terms of minimum acceptable test parameters.
Recommendation: Define the minimum acceptable NIST STS parameters (bit stream length, number of sequences) that satisfy SP 800-22 requirements.
