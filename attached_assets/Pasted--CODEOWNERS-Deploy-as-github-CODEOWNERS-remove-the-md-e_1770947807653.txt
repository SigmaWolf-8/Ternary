## What This Does

GitHub parses this file to **automatically request reviews** when a PR touches matched paths. With this config:

| Path | Effect |
|---|---|
| `libternary/` | Any Rust change requires @SigmaWolf-8 approval |
| `contracts/` | Protocol spec changes require approval |
| `shared/ternary-circle.ts` | Angular constant changes require approval |
| `server/`, `kong/`, `deployments/` | Infrastructure changes require approval |
| `.github/workflows/` | CI pipeline changes require approval |
| `docs/adr/` | Architecture decisions require approval |
| Root configs (`package.json`, `tsconfig.json`, `Cargo.toml`) | Build config changes require approval |

Place this file at `.github/CODEOWNERS` (no extension) and enable branch protection rules on `main` to enforce it.
