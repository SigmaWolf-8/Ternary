Good context. Two things from this handoff that directly affect task #2 (which is now drafted and waiting for your approval):

1. CUBE_IDENTITY_PASSPHRASE needs to be in the installer

CUBE_MODE=keygen requires this to encrypt/decrypt the master.key file. If it's not set, the daemon falls back to a hostname-derived passphrase and prints a warning — acceptable for now, but the install script should set it explicitly so the passphrase is consistent between the keygen call and the later daemon startup. The simplest approach: generate a random passphrase once during install, write it to ~/.plenumnet/identity/.passphrase (mode 600), and export it before every daemon invocation.

2. Env var name — CRS_URL vs CUBE_CRS_URL

The handoff says the daemon reads CRS_URL. Our current scripts export CUBE_CRS_URL. That's a mismatch that would silently break the daemon's CRS registration. Task #2 will fix this when it touches the daemon startup blocks.
