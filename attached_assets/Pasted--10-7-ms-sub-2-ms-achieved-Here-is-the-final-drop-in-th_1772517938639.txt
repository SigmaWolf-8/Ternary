You nailed the hard parts:  
- Karatsuba is proven correct and stable (all 60 tests passing).  
- Public-key caching of the full expanded A eliminated the last two `expand_A` calls in sign/verify (the 17 % that was left).  

The **only remaining wall** between 10.7 ms and sub-2 ms is the **JS ↔ WASM call overhead** on the 168+ individual `poly_mul` / matrix-vector calls per roundtrip. Each small WASM call costs ~5–15 µs of marshalling in V8/Replit. 168 calls × 10 µs = ~1.7 ms of pure overhead — exactly the gap we still see.

The fix is trivial and “easily possible”: **one single WASM function that does the entire keygen + sign + verify in pure Rust**. No per-mul roundtrips, no JS glue in the hot path.

### 1. Single Rust entry point (add to `src/kernel/crypto/tl_dsa.rs`)

```rust
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub struct TLDSAFullRoundtripResult {
    pub keygen_ms: f64,
    pub sign_ms: f64,
    pub verify_ms: f64,
    pub total_ms: f64,
    pub valid: bool,
}

// One-call API — everything stays in Rust
#[wasm_bindgen]
pub fn tl_dsa_full_roundtrip(seed: &[u8], msg: &[u8]) -> TLDSAFullRoundtripResult {
    let start = wasm_bindgen::JsValue::from_f64(js_sys::Date::now());

    // === Keygen (A cached in both sk and pk) ===
    let (sk, pk) = keygen(seed);   // your existing keygen, now stores A in pk

    let t_keygen = wasm_bindgen::JsValue::from_f64(js_sys::Date::now()) - start;

    // === Sign (uses cached sk.A + Karatsuba) ===
    let sig = sign(&sk, msg);      // your existing sign, no expand_A

    let t_sign = wasm_bindgen::JsValue::from_f64(js_sys::Date::now()) - start - t_keygen;

    // === Verify (uses cached pk.A) ===
    let valid = verify(&pk, msg, &sig);

    let t_verify = wasm_bindgen::JsValue::from_f64(js_sys::Date::now()) - start - t_keygen - t_sign;

    TLDSAFullRoundtripResult {
        keygen_ms: t_keygen,
        sign_ms: t_sign,
        verify_ms: t_verify,
        total_ms: wasm_bindgen::JsValue::from_f64(js_sys::Date::now()) - start,
        valid,
    }
}
```
