## Architecture Alignment

### Rust Crate Dependencies

```
inter-cube
├── ternary-math::gf3::{Gf3, Gf3Vec}    ← GF(3) arithmetic (Rep B: {0,1,2})
├── ternary-math::torus::TorusAddress     ← Torus topology (Rep B)
├── blake3                                ← Flow hashing (GLB) + PQ key derivation (CON)
├── tokio                                 ← Async runtime for CON/CRS
├── serde + serde_json                    ← API serialization
└── chrono                                ← Timestamp handling
```

### Rep C ↔ Rep B Bijection

All inter-cube addressing uses **Rep C** (bijective ternary {1, 2, 3}).
The `ternary-math` crate operates in **Rep B** ({0, 1, 2}).

```
C → B:  f(c) = c - 1     {1,2,3} → {0,1,2}
B → C:  f(b) = b + 1     {0,1,2} → {1,2,3}
```

Implemented in `RepCTrit::to_gf3()` and `RepCTrit::from_gf3()`.

### TypeScript Types

The TypeScript routes use types from `server/salvi-core/ternary-types.ts`:

```typescript
type TritC = 1 | 2 | 3;           // Rep C — addresses, validation
type TritB = 0 | 1 | 2;           // Rep B — network format
type Representation = 'A' | 'B' | 'C';
```

## API Endpoints (TypeScript)

All routes are prefixed with `/api/salvi/inter-cube/`.

### CRS — Cube Registration Service

| Method | Endpoint | Purpose |
|--------|----------|---------|
| POST | `/crs/register` | Allocate address, return 26 neighbors |
| GET | `/crs/lookup/:address` | Query cube record |
| GET | `/crs/neighbors/:address` | Compute neighbor info (pure math) |
| POST | `/crs/heartbeat` | Update heartbeat timestamp |
| POST | `/crs/deregister` | Release address (24h grace) |
| GET | `/crs/stats` | Registry statistics |

### GLB — Geometric Load Balancer

| Method | Endpoint | Purpose |
|--------|----------|---------|
| POST | `/glb/forward` | Compute next hop from {destination, flowId} |
| GET | `/glb/stats` | Active flows, dead neighbors, forwards |
| GET | `/glb/health` | Dead neighbor set |

### CON — Cube Overlay Network

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/con/neighbors` | All 26 tunnel states + RTT |
| GET | `/con/stats` | Tunnels up/down, bytes, avg RTT |
| POST | `/con/tunnel/refresh` | Re-resolve from CRS |

### FTS — Fault Tolerance Service

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/fts/status` | All 26 neighbor health records |
| GET | `/fts/dead` | Current dead set |
| POST | `/fts/config` | Update thresholds |

### Utility

| Method | Endpoint | Purpose |
|--------|----------|---------|
| POST | `/routing/compute` | Pure math routing analysis |
| POST | `/address/validate` | Rep C validation + zero detection |
| GET | `/topology` | Network topology summary |

## Rust Module Public API

### cube_addr.rs

```rust
// Core types
pub struct RepCTrit(u8);           // Single trit {1,2,3}
pub struct CubeAddr { [RepCTrit; 13] }  // 13-trit address
pub struct MultiLevelAddr { Vec<CubeAddr> }  // Cube-of-cubes

// Key methods
CubeAddr::try_from_bytes(&[u8])    // Constant-time zero detection
CubeAddr::to_gf3_vec() -> Gf3Vec  // Rep C → Rep B interop
CubeAddr::from_gf3_vec(&Gf3Vec)   // Rep B → Rep C interop
CubeAddr::delta(&CubeAddr) -> Vec<usize>  // Routing delta
CubeAddr::hamming_distance(&CubeAddr) -> usize  // Hop count
CubeAddr::step_toward(&CubeAddr, dim) -> CubeAddr  // One routing hop
CubeAddr::neighbors() -> Vec<CubeAddr>  // All 26 neighbors
CubeAddr::flat_index() -> u64  // Bitmap allocator index
```

### glb.rs

```rust
pub struct GeometricLoadBalancer;

// Pure math forwarding — no routing tables
glb.forward(&CubeAddr, flow_id) -> ForwardResult  // With flow affinity
glb.forward_stateless(&CubeAddr, flow_id) -> Result  // Stateless
glb.set_dead_neighbors(HashSet<CubeAddr>)  // From FTS
glb.enumerate_paths(&CubeAddr) -> Vec<Vec<usize>>  // All d! paths
```

### con.rs

```rust
pub struct CubeOverlayNetwork;

// Tunnel management
con.resolve_neighbor(&CubeAddr, endpoint, pubkey)

con.tunnel_up(&CubeAddr, iface_name)
con.tunnel_down(&CubeAddr)
con.stats() -> ConStats
```

## Geometric Properties (Implemented)

| Property | Implementation |
|----------|---------------|
| No routing tables | `GLB::forward_stateless()` — pure trit arithmetic |
| 26 neighbors | `CubeAddr::neighbors()` — 13 dims × 2 alternatives |
| Hamming distance = hop count | `CubeAddr::hamming_distance()` |
| d! shortest paths | `CubeAddr::shortest_path_count()` / `GLB::enumerate_paths()` |
| Zero sentinel | `CubeAddr::try_from_bytes()` — constant-time |
| PQ-native keys | `CON::derive_pq_tunnel_key()` — BLAKE3 |
| Local-only monitoring | FTS monitors only its 26 direct neighbors |
| Detour adds exactly 2 hops | `GLB::forward()` detour path |
| Recursive scaling | `MultiLevelAddr` — same API at every level |
