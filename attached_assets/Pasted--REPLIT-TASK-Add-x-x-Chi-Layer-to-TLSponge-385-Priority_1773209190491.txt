## What

Version the sponge. Keep v1 (current, no chi) for reading old data. v2 (with chi) for all new operations. Same backward compatibility pattern as phase encryption (nonce field detection).

---

## The Math

GF(27) = GF(3)[t]/(t³ + 2t + 1). Each element is a polynomial a₀ + a₁t + a₂t² with coefficients in GF(3) = {0, 1, 2}.

A 3-trit block [t₀, t₁, t₂] in balanced ternary {-1, 0, +1} maps to GF(3) coefficients {0, 1, 2} by adding 1: aᵢ = tᵢ + 1.

Multiplication in GF(27): multiply the polynomials, reduce modulo t³ + 2t + 1 with coefficients modulo 3.

χ(x) = x¹⁷. Compute via repeated squaring (square-and-multiply) in GF(27):
- x² = x · x
- x⁴ = x² · x²
- x⁸ = x⁴ · x⁴
- x¹⁶ = x⁸ · x⁸
- x¹⁷ = x¹⁶ · x

Five multiplications. Each multiplication is polynomial multiply mod (t³ + 2t + 1) mod 3.

Implement the GF(27) field arithmetic from first principles. No lookup tables. The irreducible polynomial t³ + 2t + 1 and the exponent 17 are the only constants.

## Where Chi Goes in the Round Function

Current round function (both Rust and TypeScript):
1. Theta (7-neighbor mixing with +1 constant)
2. Pi (stride-376 permutation)
3. Round constants

New round function:
1. **Chi (NEW)** — apply χ(x) = x¹⁷ to each consecutive 3-trit block
2. Theta (unchanged)
3. Pi (unchanged)
4. Round constants (unchanged)

Chi operates on the 729-trit state as 243 blocks of 3 trits each. For each block, convert balanced trits to GF(27) element, compute x¹⁷ via square-and-multiply, convert back to balanced trits.

## GF(27) Multiplication — Reference Implementation

```
Multiply polynomials a = a₀ + a₁t + a₂t² and b = b₀ + b₁t + b₂t² in GF(3)[t]:

Product (before reduction):
  c₀ = a₀·b₀
  c₁ = a₀·b₁ + a₁·b₀
  c₂ = a₀·b₂ + a₁·b₁ + a₂·b₀
  c₃ = a₁·b₂ + a₂·b₁
  c₄ = a₂·b₂

All coefficients mod 3.

Reduce mod t³ + 2t + 1 (i.e., t³ ≡ -2t - 1 ≡ t + 2 mod 3):
  t³ → t + 2
  t⁴ → t·(t + 2) = t² + 2t

So:
  r₀ = (c₀ + 2·c₃) mod 3           // c₃ contributes via t³ → t+2, the constant term is 2
  r₁ = (c₁ + c₃ + 2·c₄) mod 3      // c₃ contributes t, c₄ contributes via t⁴ → t²+2t
  r₂ = (c₂ + c₄) mod 3              // c₄ contributes t²

Result: r₀ + r₁t + r₂t²
```

## Context: Why This Is Being Done

The monograph (TM-2026-008) specified χ(x) = x¹⁷ as the chi layer and marked it "COMPLETE" — meaning the mathematical analysis was complete. The chi layer was never implemented in code. The Rust kernel sponge, the ternary-math crate sponge, and the TypeScript sponge all run theta + pi + round constants with no chi. The paper was written as though chi existed in the code because the monograph said "COMPLETE." It didn't distinguish between "math is done" and "code has it."

This task implements what was specified. After this task, the code matches the paper and the monograph. The v1 sponge (no chi) stays for backward compatibility with all existing data.
