#### 4. `server/services/threat-model.service.ts` – Threat Registry & Risk Matrix

**Key Functions Implemented**:
```typescript
createThreat(payload)
  → Validates threat_id (UNIQUE, pattern THREAT_NNN)
  → Validates likelihood/impact enums
  → Calculates risk_score = (likelihood_weight × impact_weight) / 10
     where likelihood: low=1, medium=3, high=7, very_high=10
     and   impact: low=1, medium=3, high=7, critical=10
  → Stores controls: [{control_id, control_name, status, evidence}]
  → Returns threat with calculated risk_score

listThreats(filters?: {category, mitigation_status})
  → Queries threat_model_entries with indexes
  → Groups by category and mitigation_status
  → Returns {entries: [...], count, by_category: {...}, by_status: {...}}

getThreat(threat_id)
  → Fetches with controls array
  → Returns full details for deep-dive analysis

updateThreatMitigation(threat_id, {mitigation_status, controls, residual_risk, notes})
  → Updates control_status (e.g., 'verified_by_audit')
  → Sets residual_risk (post-mitigation exposure, 0-10)
  → Updates updated_at + updated_by
  → Immutable audit trail (old values preserved in logs)

getRiskMatrix()
  → Aggregates all threats
  → Groups by category + mitigation_status
  → Returns heatmap: {
      physical: {mitigated: [3 threats], in_progress: [2], acknowledged: [0]},
      crypto: {...},
      ...
    }
  → Also returns high_risk_count (score >= 6.0)
```

**Risk Calculation Correctness**: ✅ VALIDATED

- Produces 0.1–10.0 scale (even low×low = 0.1, very_high×critical = 10.0)

**Control Tracking**: ✅ EXCELLENT

- Status tracking: implemented → in_progress → verified_by_audit

- Enables audit trail: "Control X verified by Galois on YYYY-MM-DD"

**Residual Risk Assessment**: ✅ SOUND
- Post-mitigation risk rating separate from raw risk_score
- Allows honest assessment: "Risk 7.0/10, but mitigated; residual 1.5/10"
- Used in downstream threat model doc for "Detection Only" flagging

**Alignment with Docs**: ✅ 100%

      total_loc: 156000,
      total_loc_tested: 148200,
      avg_test_coverage: 94.8%,

    }

getMilestones(from, to)
  → Queries milestone_date BETWEEN from AND to
  → Groups by milestone_date
