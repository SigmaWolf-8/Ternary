Dockerfile (65 lines) — Multi-Stage Production Build
Two stages, minimal attack surface:

Builder stage — rust:1.85-bookworm. Dependency caching trick: copies Cargo.toml first, builds a dummy, then copies real source. Compiles both binaries (tdns-scan + tdns-server) in release mode. Runs cargo test --release during build — if tests fail, the image doesn't ship.
Runtime stage — debian:bookworm-slim. Only ca-certificates installed (needed for TLS in scanner). Copies just the two binaries from builder. Non-root tdns user. Exposes port 3927. Built-in HEALTHCHECK hitting /api/v1/health every 10 seconds.

bashdocker build -t tdns-v2 .
docker run -p 3927:3927 tdns-v2                    # Server
docker run tdns-v2 tdns-scan https://github.com     # CLI
