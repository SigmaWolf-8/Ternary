The authentication flow:
Sender:
  hmac_key = derive_hb_hmac_key(address, master_secret)  ← derived once, cached
  msg = address ‖ endpoint ‖ sequence_le ‖ timestamp_le
  tag = compute_hb_hmac(hmac_key, msg)                    ← TIS-27, <1µs

Receiver (record_authenticated_pong):
  1. Check sequence > last_accepted (sliding window ±10)   → SequenceReplay
  2. Reconstruct canonical_message()
  3. verify_hb_hmac(cached_key, msg, tag)                  → HmacInvalid
     ├─ fail: consecutive_auth_failures++
     │        if failures ≥ 3 → Suspect event (same as 3 missed pings)
     └─ pass: reset failures, update SRTT/state, accept
