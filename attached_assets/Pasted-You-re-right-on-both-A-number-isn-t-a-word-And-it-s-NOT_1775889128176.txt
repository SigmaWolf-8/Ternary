What this thing IS: a ternary integer. One whole number stored in base 3. Variable precision — small values inline, large values on heap.

The name is **`TritInt`**.

- `TritInt` = one ternary integer (the scalar storage primitive)
- `Trit` = three TritInts (the algebraic triple: ℤ + φ + ω)

Clean distinction. "Int" is the mathematical term for whole number (ℤ = the integers), not a binary computing term. A ternary integer is an integer in base 3.
