Key design decisions:
The existing ternary-math/src/plenum_checksum.rs is locked to 27-trit TDNS addresses. Rather than modify it (or adding a 13-trit overload that breaks the module's contract), wire.rs implements the same Horner's method inline — identical math, no length restriction. Both use the same moduli, same Rep B conversion, same decomposition. The wire module works on 13-trit inter-cube addresses AND 27-trit TDNS addresses.
Wire encoding: 12 checksum trits pack to 3 bytes (2 bits per trit, same encoding as pack_trit_array). A checksummed address is 7 bytes: [addr(4) ‖ ck(3)]. The WireFlags::DUAL_CHECKSUM flag (0x04, already defined in T-01) signals the receiver to expect and verify the checksum.
