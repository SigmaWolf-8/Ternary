# TDNS Wiring — Instructions for Replit
# File: server/routes/tdns.ts
# Single file. Four changes.

## Overview

Two upgrades in one pass:

1. **Add TIS-27** for scan hashing (4 rounds, fastest path)
2. **Upgrade the identity sponge** from 3-neighbor/27-round to 7-neighbor/9-round (3× faster, same security margin as kernel sponge)

Both changes are breaking — all existing scan hashes AND identity anchors
will change. This is intentional. Registry is empty or near-empty.

After this change, `server/routes/tdns.ts` has two sponge constructions:

| Sponge | Rounds | Theta | Pi | Absorption | Used for |
|--------|--------|-------|----|------------|----------|
| Identity sponge | 9 (was 27) | 7-neighbor (was 3) | Scatter (unchanged) | XOR + padding (unchanged) | `deriveIdentityTrits()` |
| TIS-27 | 4 | 7-neighbor | Gather | Direct copy | Scan hash |

## Change 2: Upgrade identity sponge — `tisTheta()`

Find the existing `tisTheta` function:
```typescript
function tisTheta(s: Uint8Array): void {
  const t = new Uint8Array(TIS_STATE);
  for (let i = 0; i < TIS_STATE; i++) {
    const p = (i + TIS_STATE - 1) % TIS_STATE;
    const n = (i + 1) % TIS_STATE;
    t[i] = gf3Add(s[i], gf3Add(s[p], s[n]));
  }
  s.set(t);
}
```

Replace with:
```typescript
function tisTheta(s: Uint8Array): void {
  const t = new Uint8Array(TIS_STATE);
  const W = TIS_STATE;
  for (let i = 0; i < W; i++) {
    // 7-neighbor: ±1, ±7, ±13 — all coprime to 54, full diffusion in 3 rounds
    let left = s[(i + W - 13) % W] + s[(i + W - 7) % W] + s[(i + W - 1) % W];
    if (left >= 6) left -= 6; else if (left >= 3) left -= 3;
    let right = s[(i + 1) % W] + s[(i + 7) % W] + s[(i + 13) % W];
    if (right >= 6) right -= 6; else if (right >= 3) right -= 3;
    let sum = left + s[i] + right;
    if (sum >= 6) sum -= 6; else if (sum >= 3) sum -= 3;
    t[i] = sum;
  }
  s.set(t);
}
```

`tisPi` and `tisPermute` are NOT changed — scatter pi and the round constant
injection stay the same. Only the theta diffusion and round count change.

## Change 3: Add TIS-27 scan hash functions

Add this block AFTER `tisPermute()`, BEFORE `deriveIdentityTrits()`:

```typescript
// ── TIS-27 Integrity Hash ─────────────────────────────────────────────────────
//
// Fast ternary integrity function. Mirrors ternary-math/src/tis_sponge.rs.
// Different construction from the identity sponge above:
//   - 4 rounds (vs 9 for identity)
//   - Gather pi (vs scatter for identity)
//   - Direct copy absorption (vs XOR + padding for identity)
//
// Used for scan hashing only. NOT for identity binding.

const TIS27_ROUNDS = 4;

const TIS27_PI: number[] = (() => {
  const t: number[] = new Array(TIS_STATE);
  for (let i = 0; i < TIS_STATE; i++) t[i] = (i * 13) % TIS_STATE;
  return t;
})();

const TIS27_RC_BASE = [0,0,1,1,2,1,1,1,0,2,0,2,1,0,0,1,1,2,1,1,1,0,2,0,2,1,0];
const TIS27_RC: number[][] = (() => {
  const rcs: number[][] = [];
  for (let r = 0; r < TIS27_ROUNDS; r++) {
    const row: number[] = new Array(27).fill(0);
    for (let i = 0; i < 27; i++) {
      row[i] = TIS27_RC_BASE[(i + r) % 27];
    }
    rcs.push(row);
  }
  return rcs;
})();

function tis27Theta(s: Uint8Array): Uint8Array {
  const t = new Uint8Array(TIS_STATE);
  const W = TIS_STATE;
  for (let i = 0; i < W; i++) {
    let left = s[(i + W - 13) % W] + s[(i + W - 7) % W] + s[(i + W - 1) % W];
    if (left >= 6) left -= 6; else if (left >= 3) left -= 3;
    let right = s[(i + 1) % W] + s[(i + 7) % W] + s[(i + 13) % W];
    if (right >= 6) right -= 6; else if (right >= 3) right -= 3;
    let sum = left + s[i] + right;
    if (sum >= 6) sum -= 6; else if (sum >= 3) sum -= 3;
    t[i] = sum;
  }
  return t;
}

function tis27Pi(theta: Uint8Array): Uint8Array {
  const p = new Uint8Array(TIS_STATE);
  for (let i = 0; i < TIS_STATE; i++) {
    p[i] = theta[TIS27_PI[i]];  // GATHER — matches Rust tis_sponge.rs
  }
  return p;
}

function tis27Permute(state: Uint8Array): void {
  for (let r = 0; r < TIS27_ROUNDS; r++) {
    const t = tis27Theta(state);
    const p = tis27Pi(t);
    const rc = TIS27_RC[r];
    for (let i = 0; i < 27; i++) {
      p[i] = gf3Add(p[i], rc[i]);
    }
    state.set(p);
  }
}
```

  // ── Scan hash via TIS-27 (4-round, 7-neighbor, gather pi) ──────────────
  // Direct copy absorption — matches ternary-math/src/tis_sponge.rs exactly.
  const scanTritsGf3 = trits.map((t: number) => t - 1);

  const scanState = new Uint8Array(TIS_STATE);

## What is NOT changed

- `tisPi()` — scatter direction, unchanged (identity sponge convention)
- `tisPermute()` — still calls tisTheta + tisPi + RC injection, just faster now
- `deriveIdentityTrits()` — function body unchanged, but produces different
  output because tisTheta and TIS_ROUNDS changed underneath it
- `canonicaliseUrl()` — unchanged
- `gf3Add()` — unchanged, reused by both sponges
- `TIS_STATE = 54` — unchanged
- `TIS_RATE = 27` — unchanged
- `TIS_RC` — unchanged (same 27 round constants, just fewer rounds used)
- `scan_hash_algo: "tis-27"` — unchanged (now accurate for scan hash)
- All 27 derivation rules — unchanged
- All score computation — unchanged
- All API routes — unchanged

## What breaks

- **ALL identity anchors change.** 7-neighbor theta + 9 rounds produces different
  output from 3-neighbor + 27 rounds. Any stored identity trits are invalid.
- **ALL scan hashes change.** Different algorithm entirely (TIS-27 vs identity sponge).
- **CRD/CGUID values change.** Derived from scan output.
- **This is intentional.** Registry is empty or near-empty. Clean break.

## Summary

| Before | After |
|--------|-------|
| Identity: 27 rounds, 3-neighbor | Identity: 9 rounds, 7-neighbor |
| Scan: identity sponge (wrong primitive) | Scan: TIS-27 (correct primitive) |
| Full diffusion: 6 rounds, 4.5× margin | Full diffusion: 3 rounds, 3.0× margin |
| Identity speed: 1× | Identity speed: **~3× faster** |
| Scan speed: 1× (27 rounds, overkill) | Scan speed: **~7× faster** (4 rounds) |
