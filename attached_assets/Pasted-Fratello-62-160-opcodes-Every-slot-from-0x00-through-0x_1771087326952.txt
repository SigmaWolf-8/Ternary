System (11 new): Three-ring privilege model. Memory protection. CPUID feature detection with 16 capability bits.
Security & Audit (8 new): AUDIT for FINRA 613/CAT NMS compliance logging. Capability-based access control. Side-channel masking. Constant-time equality and selection.
Debug & Profiling (8 new): Profiling counters for CMVP benchmarking. Structured trace events. Debug assertions for ternary invariants.
