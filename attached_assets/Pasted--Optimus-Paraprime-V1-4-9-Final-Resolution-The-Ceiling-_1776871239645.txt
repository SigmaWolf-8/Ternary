### §V.1. The Miller–Rabin Non‑Witness Indicator

Let \(n\) be an odd integer coprime to \(1365 = 3\cdot5\cdot7\cdot13\). Write \(n-1 = 2^s \cdot d\) with \(d\) odd. For a base \(a\) coprime to \(n\), define the **non‑witness indicator**:
\[
w_a(n) = \begin{cases}
1 & \text{if } a^d \equiv 1 \pmod{n} \text{ or } a^{2^j d} \equiv -1 \pmod{n} \text{ for some } 0 \le j < s,\\[4pt]
0 & \text{otherwise}.
\end{cases}
\]
If \(n\) is prime, \(w_a(n) = 1\) for all \(a\) coprime to \(n\). If \(n\) is composite, the set of bases with \(w_a(n) = 1\) is the **strong liar set**, which is a proper subgroup of \((\mathbb{Z}/n\mathbb{Z})^\times\).
