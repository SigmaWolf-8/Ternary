1a. PlenumColor System
Primary file: src/kernel/src/browser/color.rs (757 lines) Mathematical foundation: src/kernel/src/distributor/coprime_polygon_pair.rs

PlenumColor is a recursive polygon mesh mapping between sRGB and a ternary coordinate space. Key properties:

540-node recursive mesh with coprime step 1,001 (7 × 11 × 13)
Depth-3 LUT guarantees ≤1 LSB round-trip error
Arc roots from the quadratic arc² − 832·arc + 118,300 = 0:
ARC_RED = 182° (within the 364° ternary circle)
ARC_GREEN = 650°
ARC_BLUE = 240 (derived as 2 × φ(143))
Bézier interpolation using arc-derived control points (4.8× quality improvement per depth level)
Pipeline position: Stage 5, after CPU rendering, before encryption
Initialization in kernel boot (src/kernel/src/main.rs):

MeshPrecision::compute(3) — set up depth-3 precision
MeshColorLut::build(3) — build the look-up table
browser.apply_mesh_color() — per-frame framebuffer processing
