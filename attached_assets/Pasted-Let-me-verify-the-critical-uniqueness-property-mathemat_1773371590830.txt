Corrects single-trit wire errors in 13-trit Rep C addresses.
Parity Group Layout
The 13 address trits are mapped to a 3×3 grid + 4-element overflow:
┌────┬────┬────┐
│ t0 │ t1 │ t2 │  → P_R0
├────┼────┼────┤
│ t3 │ t4 │ t5 │  → P_R1
├────┼────┼────┤
│ t6 │ t7 │ t8 │  → P_R2
└────┴────┴────┘
  ↓    ↓    ↓
P_C0 P_C1 P_C2

Overflow: [t9, t10, t11, t12] → P_R3

Diagonal: [t0, t4, t8, t12] → P_D0
8 parity trits = 4 rows + 3 columns + 1 diagonal. Each parity = Σ(group trits) mod 3.

t0:  R0 + C0 + D     t7:  R2 + C1

13 positions × 2 magnitudes = 26 unique syndrome patterns (verified programmatically). This guarantees single-trit error correction.
Error Correction Flow
receive(addr_packed, syndrome_packed)
    │

    ├─ Error syndrome = (received - computed) mod 3

    └─ No match? → Uncorrectable (multi-trit error detected)
