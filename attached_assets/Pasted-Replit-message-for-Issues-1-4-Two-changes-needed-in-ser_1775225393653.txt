Issue 1 — Heartbeat counter is counting HTTP polls, not heartbeats
api.rs line 964: heartbeat_counter.fetch_add(1) fires on every /slots request. Fix:
Add to AppState:
rustpub real_heartbeat_counter: AtomicU64,
pub last_heartbeat_epoch: AtomicU64,
Initialize both to AtomicU64::new(0) in both AppState::new() calls.
In main.rs heartbeat loop (~line 1182), add:
ruststate.real_heartbeat_counter.fetch_add(1, Ordering::Relaxed);
state.last_heartbeat_epoch.store(
    std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .unwrap_or_default().as_secs(),
    Ordering::Relaxed,
);
In get_slot_inventory, replace the poll-increment with a read:
rust// Remove this:
let hb = state.heartbeat_counter.fetch_add(1, Ordering::Relaxed);
// Replace with:
let hb = state.real_heartbeat_counter.load(Ordering::Relaxed);
let last_hb_epoch = state.last_heartbeat_epoch.load(Ordering::Relaxed);
Add to SlotInfo:
rustpub last_heartbeat_epoch: u64,
Populate with last_hb_epoch on each slot push.
