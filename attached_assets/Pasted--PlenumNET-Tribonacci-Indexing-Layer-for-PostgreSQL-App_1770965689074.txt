# PlenumNET Tribonacci Indexing Layer for PostgreSQL

**Applied Physics Division — Capomastro Holdings Ltd.**

---

## Overview

A PostgreSQL extension module that leverages the Tribonacci sequence's algebraic
properties — specifically the coprimality of T₇ = 13 with 28 and the self-referential
hook T₉ = 44 → T₄₄ — for database indexing, partitioning, and scheduling.

## What's in the Module

| Component | Function | Purpose |
|-----------|----------|---------|
| `tribonacci(n)` | Returns T_n | Core sequence generator |
| `tribonacci_mod(n, m)` | Returns T_n mod m | Overflow-safe modular computation |
| `tribonacci_table(n)` | Returns first n terms with mod-28 | Diagnostics & verification |
| `trad_hash_28(key)` | Maps key → shard 0–27 | **28-fold partitioning** |
| `trad_hash(key, N, m)` | Maps key → shard 0–(N-1) | Generalized N-fold partitioning |
| `tribonacci_hash(key, b)` | Avalanche hash using (13,24,44) kernel | General-purpose hashing |
| `create_partitioned_table()` | Generates DDL for hash-partitioned tables | Schema automation |
| `generate_trib_id()` | Anti-hotspot ID generator | Write distribution |
| `skip_levels` table | Precomputed Tribonacci jump distances | Skip-index support |
| `skip_lookup(pos)` | Decomposes position into Tribonacci jumps | Range query acceleration |
| `double_hash_probe()` | Collision resolution via 13-step | Hash table probing |
| `next_worker()` | Round-robin scheduler | Load balancing |
| `verify_28fold_coverage()` | Residue coverage analysis | Mathematical verification |
| `verify_permutation()` | 13-step completeness proof | Mathematical verification |
| `demonstrate_hook()` | Shows T₉=44 → T₄₄ | Educational / demo |

## Important Mathematical Finding

During verification, we confirmed that **Tribonacci mod 28 visits only 20 of the 28
residues** (missing: {6, 10, 11, 14, 15, 21, 23, 26}), not all 28 as originally
theorized. However, this does **not** affect the indexing layer because:

- The **13-step permutation** `(key × 13) mod 28` is the actual engine for full
  coverage, and it is mathematically proven to visit all 28 positions (since
  gcd(13, 28) = 1).
- The Tribonacci sequence provides the **constants** (13, 24, 44) used as mixing
  coefficients, not as direct partition selectors.
- The self-referential hook (T₉ = 44 → T₄₄ = 80,641,778,674) and the identity
  13 × 28 = 364 = 111111₃ remain fully verified.

This is a refinement of the theory: the sequence **generates** the coprime constant 13,
and that constant — applied as a multiplicative permutation — is what delivers the
full 28-fold symmetry. The distinction is between the sequence's internal residue
coverage (partial) and the derived permutation's coverage (complete).
