## 1. Overview

The Ternary Virtual Machine (TVM) ISA v2.0 extends the original 62-opcode instruction set to **160 opcodes**, targeting enterprise-grade deployment for post-quantum cryptographic systems, HPTP femtosecond timing, financial compliance (FINRA Rule 613 / CAT NMS), and the Sigma Wolf ET trading protocol.

Key v2.0 additions:

- **Extended arithmetic**: fused multiply-accumulate, min/max/clamp, immediate-add
- **Atomic operations**: compare-and-swap, exchange, atomic add, memory fences
- **Extended control flow**: indirect call, tail call, loop counter, jump table, interrupt return
- **Selection & bit manipulation**: conditional moves, popcount, CLZ/CTZ, rotate, PDEP/PEXT, CRC32
- **Extended crypto acceleration**: lattice multiply, sponge absorb/squeeze, Lamport OTS, KEM encaps/decaps, secure zeroize
- **Full SIMD vector suite**: all ternary ops vectorized, plus broadcast/extract/insert/permute
- **Security & audit**: FINRA-compliant audit logging, capability-based access control, constant-time operations, side-channel masking
- **Debug & profiling**: breakpoints, profiling counters, trace events, assertions
- **Three-ring privilege model**: Ring0 (kernel), Ring1 (user), Ring2 (service/driver)

Backward compatibility: all 62 v1.0 opcodes retain their original hex values and semantics.

## 2. Register File (v2.0 Extended)

### 2.1 General-Purpose Registers

| Register | Width | Description |
|----------|-------|-------------|
| r0–r26 | 64-bit | General-purpose; each has an independent `ternary_mode` flag |

### 2.2 Special Registers

| Register | Width | Description |
|----------|-------|-------------|
| PC | 64-bit | Program counter (instruction index) |
| SP | 64-bit | Stack pointer |
| FP | 64-bit | **v2.0** Frame pointer for call frames |
| LR | 64-bit | **v2.0** Link register (return address) |

### 2.3 Flags Register (v2.0 Extended)

| Flag | Set when… |
|------|-----------|
| zero | Result == 0 |
| negative | Result < 0 (signed) |
| positive | Result > 0 |
| overflow | Arithmetic overflow detected |
| ternary | (per-register) Register contains packed trit data |
| halted | HALT instruction has executed |
| **carry** | **v2.0** Unsigned overflow / borrow detected |
| **parity** | **v2.0** Result has even number of set bits |
| **interrupt_enabled** | **v2.0** Interrupts are enabled (default: true) |

### 2.4 Privilege Levels (v2.0 Extended)

| Level | Value | Description |
|-------|-------|-------------|
| Ring0 | 0 | Kernel / supervisor — full access |
| Ring1 | 1 | User — restricted |
| **Ring2** | **2** | **v2.0** Service / driver — intermediate privilege |

## 3. Instruction Encoding Formats

Unchanged from v1.0. All three formats accommodate the full 0x00–0x9F opcode range.

- **Legacy**: 16 bytes (full 64-bit immediate)
- **Compact**: 4 or 6 bytes (16-bit immediate)
- **Balanced Ternary**: 5 or 7 bytes (9-trit opcode encoding)
