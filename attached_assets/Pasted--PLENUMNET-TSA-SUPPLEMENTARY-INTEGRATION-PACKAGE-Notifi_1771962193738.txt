## TRIAGE NOTES (What Was Evaluated and Why)

| Proposed Item | Verdict | Rationale |
|---------------|---------|-----------|
| Phase validation + startup warning | **ACCEPTED** | Catches env var typos, zero risk |
| `X-PlenumNET-TSA-Token-Size` header | **REJECTED** | Derivable from token header; if MTA truncates token, this header gets truncated too — doesn't solve its own use case |
| Per-channel legacy fallback | **DEFERRED** | Good idea, wrong timing — adds branching to Phase 2 which should be the simplest additive step; revisit if channel-specific rollout needed |

| `legacy_fallback_total` counter | **ACCEPTED** | Distinct from request counter status label; Phase 3 alert is the real value |
| Diff patch | **REJECTED** | Superseded by the verified final package; diff against hypothetical old file adds confusion |
| Prometheus recording rules | **ACCEPTED** | Pre-computed metrics for dashboards; standard practice |

### 3A. Node.js Reference (`webhook-verifier.ts`)

```typescript
/**
 * PlenumNET / Maestro Webhook TSA Token Verifier
 * Reference implementation for downstream consumers.
 *
 * Provides ONLINE verification via PlenumNET's /api/tsa/verify endpoint.
 * For OFFLINE verification, use OpenSSL CLI (see bash examples below)
 * or implement full CMS/TSTInfo parsing with pkijs + asn1js.
 *
 * Usage:
 *   const result = await verifyWebhookTsaToken(req.body, req.headers);
 *   if (result.valid) { processWebhook(req.body); }
 */

import * as crypto from 'crypto';

// ── Configuration ──────────────────────────────────────────────────────────
const TSA_BASE_URL = process.env.PLENUMNET_TSA_URL || 'https://plenumnet.replit.app';

// ── Types ──────────────────────────────────────────────────────────────────
export interface TsaVerificationResult {
  valid: boolean;
  method: 'online' | 'hash-only' | 'none';
  serial?: string;
  genTime?: string;
  policyTier?: string;
  merkleLeaf?: string;
  proofSummary?: string;
  reason: string;
}

// ── Header normalization ───────────────────────────────────────────────────
// Express lowercases all headers. Other frameworks may not.
// Normalize once, reference everywhere.
function getHeader(
  headers: Record<string, string | string[] | undefined>,
  name: string,
): string | undefined {
  const lower = name.toLowerCase();
  const val = headers[lower] || headers[name];
  if (Array.isArray(val)) return val[0];
  return val as string | undefined;
}

// ── Main verification function ─────────────────────────────────────────────
export async function verifyWebhookTsaToken(
  payload: string | Buffer,
  headers: Record<string, string | string[] | undefined>,
): Promise<TsaVerificationResult> {

  // 1. Extract TSA token from headers
  const tsaTokenBase64 = getHeader(headers, 'X-PlenumNET-TSA-Token');
  if (!tsaTokenBase64) {
    return {
      valid: false,
      method: 'none',
      reason: 'Missing X-PlenumNET-TSA-Token header',
    };
  }

  let tsaTokenBuffer: Buffer;
  try {
    tsaTokenBuffer = Buffer.from(tsaTokenBase64, 'base64');
  } catch {
    return {
      valid: false,
      method: 'none',
      reason: 'Invalid base64 in X-PlenumNET-TSA-Token',
    };
  }

  // 2. Extract optional metadata headers (for logging, not for trust)
  const proofSummary = getHeader(headers, 'X-PlenumNET-Proof-Summary');

  // 3. Recompute payload hash (SHA-256, matching TSA service)
  const payloadBuffer = Buffer.isBuffer(payload)
    ? payload
    : Buffer.from(payload, 'utf-8');
  const computedHash = crypto.createHash('sha256')
    .update(payloadBuffer)
    .digest('hex');

  // 4. Online verification — POST token to PlenumNET /api/tsa/verify
  //    This is the recommended path for most consumers.
  //    For offline verification, see the OpenSSL and pkijs examples below.
  try {
    const res = await fetch(`${TSA_BASE_URL}/api/tsa/verify`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/octet-stream' },
      body: tsaTokenBuffer,
    });

    if (!res.ok) {
      throw new Error(`Verify endpoint returned ${res.status}`);
    }

    const data = await res.json() as {
      valid: boolean;
      serialNumber?: string;
      genTime?: string;
      policyTier?: string;
      merkleLeafHash?: string;
      reason?: string;
    };

    if (data.valid) {
      return {
        valid: true,
        method: 'online',
        serial: data.serialNumber,
        genTime: data.genTime,
        policyTier: data.policyTier,
        merkleLeaf: data.merkleLeafHash,
        proofSummary,
        reason: 'Online verification succeeded',
      };
    } else {
      return {
        valid: false,
        method: 'online',
        reason: data.reason || 'Token verification failed',
      };
    }

  } catch (err) {
    // Online verification unavailable — fall back to hash-only check.
    // This confirms payload integrity but NOT timestamp authenticity.
    // For full offline verification, use OpenSSL (see examples below).
    console.warn('Online TSA verification failed, falling back to hash check', {
      error: (err as Error).message,
    });

    return {
      valid: false,
      method: 'hash-only',
      proofSummary,
      reason: `Online verification unavailable: ${(err as Error).message}. ` +
        'Use OpenSSL offline verification for full cryptographic proof.',
    };
  }
}
```

### 3B. Python Reference (`webhook_verifier.py`)

```python
"""
PlenumNET / Maestro Webhook TSA Token Verifier — Python Reference

Online verification via /api/tsa/verify.
For offline, use OpenSSL CLI or asn1crypto + cryptography libraries.
"""

import base64
import hashlib
import requests
from typing import Optional

TSA_BASE_URL = "https://plenumnet.replit.app"


def verify_webhook_tsa_token(
    payload: bytes,
    headers: dict,
) -> dict:
    """
    Verify TSA token on an incoming webhook.

    Returns dict with: valid, method, serial, genTime, policyTier, reason
    """
    result = {"valid": False, "method": "none", "reason": ""}

    # 1. Extract token (normalize header case)
    tsa_b64 = (
        headers.get("X-PlenumNET-TSA-Token")
        or headers.get("x-plenumnet-tsa-token")
    )
    if not tsa_b64:
        result["reason"] = "Missing X-PlenumNET-TSA-Token header"
        return result

    try:
        tsa_bytes = base64.b64decode(tsa_b64)
    except Exception as e:
        result["reason"] = f"Invalid base64 token: {e}"
        return result

    # 2. Recompute payload hash
    computed_hash = hashlib.sha256(payload).hexdigest()

    # 3. Online verification
    try:
        resp = requests.post(
            f"{TSA_BASE_URL}/api/tsa/verify",
            data=tsa_bytes,
            headers={"Content-Type": "application/octet-stream"},
            timeout=5,
        )
        resp.raise_for_status()
        data = resp.json()

        if data.get("valid"):
            return {
                "valid": True,
                "method": "online",
                "serial": data.get("serialNumber"),
                "genTime": data.get("genTime"),
                "policyTier": data.get("policyTier"),
                "reason": "Online verification succeeded",
            }
        else:
            return {
                "valid": False,
                "method": "online",
                "reason": data.get("reason", "Token verification failed"),
            }

    except Exception as e:
        return {
            "valid": False,
            "method": "hash-only",
            "reason": (
                f"Online verification unavailable: {e}. "
                "Use OpenSSL for offline verification."
            ),
        }
```

### 3C. Offline Verification (OpenSSL CLI — production recommended)

```bash
#!/usr/bin/env bash
# verify-webhook-tsa.sh — Offline TSA token verification
# No network call required after initial cert download.

set -euo pipefail

PAYLOAD_FILE="${1:?Usage: $0 <payload-file> <tsa-token-b64>}"
TSA_TOKEN_B64="${2:?Usage: $0 <payload-file> <tsa-token-b64>}"
TSA_CERT="${TSA_CERT_FILE:-plenumnet-tsa.pem}"

# Download cert if not cached
if [ ! -f "$TSA_CERT" ]; then
  echo "Downloading PlenumNET TSA certificate..."
  curl -s https://plenumnet.replit.app/api/tsa/certificate/download -o "$TSA_CERT"
fi

# Decode token
echo "$TSA_TOKEN_B64" | base64 -d > /tmp/webhook.tsr

# Compute SHA-256 hash of payload
DIGEST=$(sha256sum "$PAYLOAD_FILE" | awk '{print $1}')

# Verify
echo "Verifying TSA token..."
echo "  Payload hash: $DIGEST"
echo "  Token file:   /tmp/webhook.tsr"
echo "  TSA cert:     $TSA_CERT"
echo ""

openssl ts -verify \
  -digest "$DIGEST" \
  -in /tmp/webhook.tsr \
  -CAfile "$TSA_CERT"

# Exit code 0 = Verification: OK
# Exit code 1 = Verification: FAILED
```

### 4A. Modify `tsa-service.ts` — Add serial index

```typescript
// ── Add class member ──────────────────────────────────────────────────────
private serialIndex: Map<string, TsaTokenRecord> = new Map();

// ── Modify logToken() — add index maintenance after existing push ─────────
private logToken(record: TsaTokenRecord): void {
  this.tokenLog.push(record);

  // Maintain serial index for O(1) lookup
  this.serialIndex.set(record.serialNumber, record);

  // Existing log rotation (keep last 50K on overflow)
  if (this.tokenLog.length > 100000) {
    this.tokenLog = this.tokenLog.slice(-50000);

    // Rebuild serial index after rotation (purge stale entries)
    this.serialIndex.clear();
    for (const r of this.tokenLog) {
      this.serialIndex.set(r.serialNumber, r);
    }
  }

  // ... existing disk persistence (token-audit.jsonl) unchanged ...
}
```

### 4B. Add public lookup method

```typescript
/**
 * Lookup a single TSA token record by serial number.
 * O(1) via in-memory index. Returns null if not found or purged by rotation.
 *
 * Used by:
 * - Notification service (internal cross-reference: delivery ID → TSA record)
 * - Audit query endpoint (external: serial → full record + Merkle proof)
 */
public getTokenBySerial(serialNumber: string): TsaTokenRecord | null {
  return this.serialIndex.get(serialNumber) || null;
}
```

### 4C. Extend queryTokenLog — add serial filter

```typescript
  queryTokenLog(filters: {
    since?: string;
    until?: string;
    hashAlgorithm?: string;
    policyTier?: string;
    serialNumber?: string;    // ← ADD: exact serial match (fast path)
    limit?: number;
  }): { total: number; merkleRoot: string; merkleDepth: number; merkleLeaves: number; tokens: TsaTokenRecord[] } {

    // Fast path: serial lookup
    if (filters.serialNumber) {
      const record = this.getTokenBySerial(filters.serialNumber);
      return {
        total: record ? 1 : 0,
        merkleRoot: this.merkleLog.getRoot(),
        merkleDepth: this.merkleLog.getDepth(),
        merkleLeaves: this.merkleLog.getSize(),
        tokens: record ? [record] : [],
      };
    }

    // Existing filter logic (unchanged)
    let records = [...this.tokenLog];
    if (filters.since) records = records.filter(r => r.createdAt >= filters.since!);
    if (filters.until) records = records.filter(r => r.createdAt <= filters.until!);
    if (filters.hashAlgorithm) records = records.filter(r => r.hashAlgorithm === filters.hashAlgorithm);
    if (filters.policyTier) records = records.filter(r => r.policyTier === filters.policyTier);
    records.sort((a, b) => b.createdAt.localeCompare(a.createdAt));

    return {
      total: records.length,
      merkleRoot: this.merkleLog.getRoot(),
      merkleDepth: this.merkleLog.getDepth(),
      merkleLeaves: this.merkleLog.getSize(),
      tokens: records.slice(0, filters.limit || 100),
    };
  }
```

### 4D. Add query endpoint to TSA routes

```typescript
// GET /api/tsa/audit/query
// Extends existing /api/tsa/audit (admin-only token listing) with
// queryable lookup by serial, time range, policy tier.
//
// Serial lookup is the primary use case — notification service stores
// TSA serial in delivery log; this endpoint closes the loop.
//
// Auth: readonly or admin role. Rate limited.

router.get('/audit/query',
  rateLimit({ windowMs: 60_000, max: 30 }),
  requireAuth('readonly'),
  (req: Request, res: Response) => {
    const filters: {
      since?: string;
      until?: string;
      hashAlgorithm?: string;
      policyTier?: string;
      serialNumber?: string;
      limit?: number;
    } = {};

    if (req.query.serialNumber) filters.serialNumber = req.query.serialNumber as string;
    if (req.query.since)        filters.since = req.query.since as string;
    if (req.query.until)        filters.until = req.query.until as string;
    if (req.query.hashAlgorithm) filters.hashAlgorithm = req.query.hashAlgorithm as string;
    if (req.query.policyTier)   filters.policyTier = req.query.policyTier as string;
    if (req.query.limit)        filters.limit = Math.min(parseInt(req.query.limit as string, 10), 500);

    // queryTokenLog handles both serial fast-path and general query
    const result = service.queryTokenLog(filters);

    if (filters.serialNumber && result.total === 0) {
      return res.status(404).json({
        error: 'Serial number not found',
        serialNumber: filters.serialNumber,
        hint: 'Record may have been purged by log rotation (>100K tokens)',
      });
    }

    res.json(result);
  },
);
```

```bash
# The merkleRoot in the response is the current tree root
# An independent observer can verify the leaf is included in the root
ROOT=$(echo "$AUDIT" | jq -r '.merkleRoot')
echo "Merkle leaf: $LEAF"
echo "Merkle root: $ROOT"
echo "Leaf is cryptographically bound to root via the Merkle tree"

# 5. Additionally: verify the TSA token itself with OpenSSL
echo "$TOKEN_BASE64" | base64 -d > token.tsr
openssl ts -verify -digest "$HASH" -in token.tsr -CAfile plenumnet-tsa.pem
```

## NON-NEGOTIABLE RULES (Reinforced)

1. **Proof summary is informational.** Consumers MUST verify using the full TSA token, not the summary header. The summary is for human debugging only.

2. **Online verification is the recommended consumer path.** Offline verification requires ASN.1 parsing expertise. OpenSSL CLI is the pragmatic offline option.

3. **The webhook verifier reference code does NOT implement offline verification.** It explicitly states this. No placeholder `return true`. Consumers wanting offline must use OpenSSL or a full RFC 3161 library.

4. **Audit query endpoint is rate-limited and authenticated.** No anonymous access. Scoped JWTs with short TTL for external auditors.

5. **Serial index is rebuilt on log rotation.** The `Map.clear()` + rebuild pattern prevents stale entries from accumulating after the 100K→50K trim.

6. **The query endpoint uses `queryTokenLog()` for all responses.** It does not reach into `service.merkleLog` directly. Merkle metadata comes through the existing return structure.
