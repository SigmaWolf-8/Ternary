glb.rs (833 lines, 13 tests) — Geometric Load Balancer
The data-plane forwarding engine, per §12.4. Each node runs a GLB instance that makes local forwarding decisions:

forward_point() — Greedy geometric forwarding with dead-node avoidance. Walks differing dimensions in priority order (WHO first), skips dead/degraded neighbors, falls back to next differing dimension. Checks drift redirects before routing.
forward_subcube() — Sub-cube multicast (§11.3–11.4). Tests local membership against the wildcard mask. Fans out to qualifying neighbors along unconstrained dimensions in ascending order. Natural spanning tree, zero additional state.
forward_anycast() — Closest match by Hamming distance with deterministic tiebreaker (lowest canonical address, §11.5). Filters out dead/degraded candidates before selecting.
check_hptp() — HPTP enforcement (§10.4). If destination is HPTP-mandatory (trits 15+16 both = 3) and marked degraded, packet is dropped. No stale timing gets through.
HPTP state machine — Three states: Healthy → HptpDegraded → HptpHolddown → Healthy. Degradation triggered when FTS heartbeat reports offset exceeding tolerance (1μs for real-time). Recovery enters 5-second hold-down before resuming routing. Non-mandatory nodes are never tracked.
route() — Unified entry point: HPTP check → redirect check → point forward. Clean pipeline.
