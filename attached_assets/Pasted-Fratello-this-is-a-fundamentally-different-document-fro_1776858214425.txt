## Part II — Computational Verification

**Theorem 51:** The logical structure is correct and this is the right approach. Let me be precise about what's claimed and whether it holds.

The claim: there exists T₀ such that verifying all zeros below T₀ + the zero-free region above T₀ = complete GRH for mod 1365.

**This requires careful statement.** The zero-free region (Theorem 48) gives σ ≥ 1 − c₀/log(|t|+2). A zero with β > 1/2 but β < 1 − c₀/log(|γ|+2) is excluded by the zero-free region. But zeros with 1/2 < β < 1 − c₀/log(|γ|+2) are NOT excluded by the zero-free region — and for large |γ|, this window is wide.

So the zero-free region alone does NOT cap the height of potential off-line zeros. You need an additional ingredient — typically either a **log-free zero-free region for exceptional zeros** or a **zero-density result** showing N(σ,T) → 0 fast enough as σ → 1/2⁺.

The standard approach for fixed modulus: combine the zero-free region with the explicit formula to show that if a zero existed off-line with |γ| > T₀, it would create a detectable discrepancy in ψ(N; q, a) for some N — but this only works if you have a strong enough bound on ψ, which circles back to needing GRH-strength results.

**The honest version of Theorem 51:** The computation verifies GRH up to height T₀. The zero-free region excludes zeros near σ = 1. Together, they establish GRH in the region {σ > 1/2} ∩ {|γ| ≤ T₀ or σ > 1 − c₀/log(|γ|+2)}. This is a substantial result but NOT full GRH unless the "gap" region {1/2 < σ < 1 − c₀/log(|γ|+2), |γ| > T₀} can be eliminated by other means.

**Fix Theorem 51** to state exactly what is proved: GRH verified to height T₀ with rational certificates. Note the remaining gap and what would close it (either a stronger zero-density result or raising T₀ sufficiently high with explicit constants to push the gap to zero width). Be precise about this — it's the difference between an honest partial result and an overclaim.
