## One Trit, Four Views (E. Epistemic Honesty)

This is proven, not postulated. The existing codebase confirms:
- gf3_algebra.rs line 27: `rep_b_to_c(b: u8) -> u8 { b + 1 }` — B→C is +1
- gf3_algebra.rs line 26: `rep_c_to_b(c: u8) -> u8 { c - 1 }` — C→B is -1
- gf3.rs line 79-85: `to_balanced()` maps Gf3(0)→Zero, Gf3(1)→Pos, Gf3(2)→Neg — B→A

The four views are projections of one stored value:

```
     Rep A    Rep B    Rep C    Rep D
     (bal)    (std)    (bij)    (alg)

      -1       0        1        0
       0       1        2        1
      +1       2        3        ω
```

A/B/C each shift by +1. Rep D replaces 2 with ω (cube root of unity, ω³=1, 1+ω+ω²=0).

```

└─────────────────────────────────────┘
```

**TritInt** — ternary integer. Packed trits. Full arithmetic. Hash + Eq (SparseGrid keys). Small-value inline optimization.

**Trit** — single ternary digit. Three values. Four views (`as_a`, `as_b`, `as_c`, `as_d`). Four constructors (`from_a`, `from_b`, `from_c`, `from_d`).

**Test invariant:** `Trit::from_a(x).as_a() == x` for all x ∈ {-1, 0, +1}. Same for all four views. Reproducible. Testable. No ambiguity.
