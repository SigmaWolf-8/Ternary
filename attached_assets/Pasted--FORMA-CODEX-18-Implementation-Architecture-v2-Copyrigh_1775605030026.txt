## 2. Import Map — What Each New Module References

### 2.1 coprime.rs (NEW shared)

| Imports From | What It Uses |
|-------------|-------------|
| `constants.rs` | COPRIME_PAIRS (9), COPRIME_TRIPLES (7), COPRIME_QUADRUPLES (2), COPRIME_QUINTUPLES (5), COPRIME_SEXTUPLES (4), all LCMs, `repunit(n)` function |
| `torus.rs` | `TorusAddress` concepts — the grid IS a 2D torus, coprime topology builds on this |
| `ternary_circle.rs` | `Z28` cyclic group type, 364° geometry — walk positions map to Z₂₈ |

**Provides:**
- Public `gcd()`, `is_coprime()` — replaces 3 private scattered copies
- `CoprimePair` validated struct (gcd=1 guaranteed by construction)
- `CoprimePair::topology()` → `TorusTopology { gcd, cycle, hamiltonian }`
- `HamiltonianWalk` — 2D torus, (+1,+1) mod (X,Y), `forward()`/`backward()`/`stay()` with Rep B {1,2,0} keys
- `HamiltonianWalk::reading_order()` — row-major for same bounds
- `HamiltonianWalk::step_at(col, row)` → step number at position
- `coprime_options(axis, min, max)` → `Vec<u32>` valid partners

**Consolidates:** The same math currently scattered across `coprime_clock_rotation.rs` (kernel), `coprime_walk.rs` (kernel), `coprime_polygon_pair.rs` (kernel), `container_decomp.rs`, `cpd.rs`. Those consumers can import from this after it exists.

### 2.2 repc.rs (NEW shared)

| Imports From | What It Uses |
|-------------|-------------|
| `constants.rs` | `REPUNIT_3` for guard marker construction |
| `cube_addr.rs` | Pattern reference — the `assert!(t >= 1 && t <= 3)` zero-exclusion that repc.rs formalizes |

**Provides:**
- `validate_address(coords: &[u32])` — any zero → `RepCViolation`
- `validate_cell_address(x, y, z, face)` — 4-coordinate check
- `validate_bounds(x, y, max_x, max_y)` — range check after zero check
- `GUARD_MARKER: u64` = `0x0D0D_0D0D_0D0D_0D0D`
- `guard_intact(value)` → bool

### 2.3 sparse.rs (NEW shared)

| Imports From | What It Uses |
|-------------|-------------|
| Standalone | No framework imports |

**Provides:**
- `SparseEntry { index: u32, data: Vec<u8> }`
- `sparse_encode(items, serialize_fn)` → `Vec<SparseEntry>` — skips None entries
- `sparse_decode(entries, total_size, deserialize_fn)` → `Vec<Option<T>>`
- `sparse_ratio(total, populated)` → f64

### 2.4 forma_codex/grid.rs (NEW, application-specific)

| Imports From | What It Uses |
|-------------|-------------|
| `coprime.rs` | `CoprimePair`, `HamiltonianWalk`, `coprime_options()` |
| `constants.rs` | Framework constants for validation |

### 2.5 forma_codex/cell.rs (NEW, application-specific)

| Imports From | What It Uses |
|-------------|-------------|
| `repc.rs` | `GUARD_MARKER`, `guard_intact()` |
| `gf3.rs` | `Gf3` type, arithmetic ops — face link computation: `activeFace = ((sum of faces) mod 3) + 1` |
| `tribonacci.rs` | `TernaryRepr` enum (Rep A/B/C), `TritVec` — walk steps use Rep B {0,1,2}, addresses use Rep C {1,2,3} |

### 2.6 forma_codex/document.rs (NEW, application-specific)

| Imports From | What It Uses |
|-------------|-------------|
| `sparse.rs` | `sparse_encode()`, `sparse_decode()`, `sparse_ratio()` |

### 2.7 forma_codex/preset.rs (NEW, application-specific)

| Imports From | What It Uses |
|-------------|-------------|
| `coprime.rs` | `coprime_options()` for custom dialog |
| `constants.rs` | UV spectral wavelengths (λ_EUV=91, λ_UVC=182, λ_UVB=286, λ_UVA=364) — grid cell counts match these wavelengths in §20.2 presets |
