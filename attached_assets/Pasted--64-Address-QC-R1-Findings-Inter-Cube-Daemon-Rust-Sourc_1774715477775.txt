#64 - Address QC-R1 Findings: Inter-Cube Daemon (Rust Source)
What & Why
The daemon-wide QC-R1 review produced 44 findings (6 CRITICAL / 22 IMPORTANT / 12 MINOR / 4 positive verifications) against the Rust daemon source. All three agents issued FAIL. The CRITICAL findings include unsigned relay auth fallback, hostname-derived passphrase, cluster shell allowlist bypass, unauthenticated terminal-open (RCE), missing TIS-27 binary checksum, and unauthenticated cluster APIs. These must be resolved before the daemon can proceed to QC-R2.

Tasks
Fix unsigned relay auth fallback — Remove plaintext fallback in ws_relay.rs. Require TL-DSA challenge-response for all relay connections.
Fix hostname-derived passphrase — Replace hostname-based passphrase derivation with OS CSPRNG + DPAPI-protected storage in identity.rs.
Fix cluster shell allowlist bypass + env/printenv leak — Enforce strict command allowlist in cluster_shell.rs. Block env, printenv, set, and all environment-leaking commands. Add metacharacter filtering.
Fix unauthenticated terminal-open — Add TL-DSA authentication to the /terminal/open WebSocket endpoint.
Fix unauthenticated cluster APIs — Add TL-DSA authentication to all cluster management endpoints (/cluster/exec, /cluster/peers, etc.).
Add TIS-27 binary self-verification — Implement --verify-self mode or CUBE_MODE=hash-file for binary integrity checking.
Address IMPORTANT findings — Work through the 22 IMPORTANT findings: relay auth hardening, cluster shell sanitization, terminal session limits, identity key protection, key rotation edge cases, etc.
Address MINOR findings — Work through the 12 MINOR findings.
Update consolidated report — Mark each finding's resolution status in .local/qc-r1-inter-cube/qc-r1-consolidated.md.
