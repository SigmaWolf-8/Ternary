#93 - QC-R1 Review: MSI Installer Script
What & Why
Run a full QC-R1 (Round 1 Technical Verification) review against the PlenumNET MSI Installer script. The review must cover BOTH versions of the script:

The served version: client/public/install/install-plenumnet-msi.ps1 (724 lines, served to users via /api/install-msi)
The root version: install-plenumnet-msi.ps1 (527 lines, appears to be an older/diverged copy)
The .bat launcher generated inline in server/index.ts at the /api/install-msi.bat route
Additionally, the review must evaluate the product manifest files that define what gets installed:

tools/plenum-launcher/plenum-app.toml (Launcher manifest, defines kind = "tray_agent")
ninja-exec/plenum-app.toml (NinjaExec manifest, defines kind = "tray_agent")
Known Issues to Evaluate
The following issues have been identified and MUST be assessed by the reviewers:

Missing products in served installer: The served version (client/public/install/) only builds and installs the Launcher. NinjaExec and Inter-Cube Daemon are completely absent from $Products and $allCrates. The root version includes all three. This divergence means users get an incomplete installation.

Tray agent behavior undisclosed: Both the Launcher and NinjaExec are defined as kind = "tray_agent" with autostart = true in their manifests. The installer never tells the user that these applications will run from the Windows system tray, auto-start with Windows, or what the tray icon represents.

Unicode encoding crash: Em dash characters (U+2014) on lines 30 and 140 of the served .ps1 cause Windows PowerShell 5.1 to fail with parse errors when the file is downloaded via Invoke-WebRequest. This is the root cause of the "instant crash on click" bug.

Script divergence: Two different copies of the installer exist with different $Products, $allCrates, $ErrorActionPreference settings, and different Test-Command implementations. Which is authoritative?
