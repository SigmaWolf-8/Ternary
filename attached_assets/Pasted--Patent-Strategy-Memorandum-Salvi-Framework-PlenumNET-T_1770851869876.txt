## 2. Grace Period Alert

Under U.S. patent law, an inventor has a **one-year grace period** from the date of first public disclosure to file a patent application (35 U.S.C. §102(b)(1)(A)). However, most foreign jurisdictions have **no grace period** — public disclosure before filing destroys novelty worldwide.

The repository at https://github.com/SigmaWolf-8/Ternary is publicly visible. The earliest commit date establishes the potential disclosure date. **Patent counsel should review the git log to determine which inventions may still fall within the U.S. grace period and which, if any, have been barred by foreign absolute novelty requirements.**

Provisional patent applications ($320 USPTO filing fee for small entity, $160 for micro entity) can be filed quickly to secure a priority date while full applications are prepared. This is strongly recommended for any high-priority inventions identified below.

## 5. Patent Claim Strategy

### 5.1 Claim Types

For maximum protection, each application should include a combination of:

- **Method claims** — the steps performed by the algorithm/protocol
- **System claims** — the computing system configured to perform the method
- **Computer-readable medium claims** — the software embodying the method
- **Apparatus claims** (for THDL) — the hardware synthesized by the language

### 5.2 Alice/Mayo Considerations

Under *Alice Corp. v. CLS Bank* (2014) and *Mayo Collaborative Services v. Prometheus Laboratories* (2012), abstract ideas implemented on a generic computer are not patentable. To survive Alice scrutiny, claims should emphasize:

- **Technical improvement** — e.g., HPTP achieves femtosecond precision where existing protocols achieve nanosecond; Phase Encryption provides tamper detection that existing methods lack
- **Specific implementation** — tie claims to concrete computational steps, specific data structures, and measurable performance metrics
- **Non-obvious combinations** — the integration of Tribonacci constants with GF(3) arithmetic with post-quantum cryptography is not an abstract idea; it's a specific technical architecture

Patent counsel experienced in software patent prosecution post-Alice should be engaged for claim drafting.

## 7. Trade Secret Alternative

For innovations where patent disclosure is strategically undesirable (e.g., if describing the Phase Encryption methodology in a published patent application would aid adversaries), **trade secret protection** under the Defend Trade Secrets Act (DTSA, 18 U.S.C. §1836) is an alternative. Trade secrets require:

- The information derives independent economic value from not being generally known
- Reasonable measures are taken to maintain secrecy

The proprietary license, source file headers, confidentiality provisions, NDA requirements for enterprise customers, and access controls already in place or recommended in this engagement collectively support trade secret claims. Patent counsel should advise on the patent-vs-trade-secret decision for each invention.
