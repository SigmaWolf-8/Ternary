fts.rs (576 lines, 10 tests) — Fault Tolerance Service
Heartbeat-based failure detection per §12.3:

Heartbeat struct — Source address, HPTP timestamp, HPTP offset, monotonic sequence number, HPTP-mandatory flag. This is the wire format FTS nodes exchange.
Three-state health model — Alive → Suspect → Dead. Configurable thresholds: 1 missed → suspect (default), 3 missed → dead (default). Clean transitions with event emission at each boundary.
process_heartbeat() — Accepts a heartbeat, updates node record, detects sequence anomalies (out-of-order/replay), emits recovery events when dead nodes come back. HPTP-mandatory nodes emit HptpUpdate events on every heartbeat for GLB consumption.
check() — Periodic sweep. Increments missed counts for silent nodes, transitions states, emits NodeSuspect and NodeDead events. Call at heartbeat interval.
Sequence anomaly detection — Tracks monotonic sequence per node. Out-of-order heartbeats flagged and counted. Catches replay and reordering.
Event-driven — All state changes emit FtsEvent variants that GLB and CRS consume: NodeAlive, NodeSuspect, NodeDead, NodeRecovered, HptpUpdate, SequenceAnomaly. No polling.


con.rs (539 lines, 14 tests) — Cube Overlay Network
PQ-native encrypted tunnels per §12.2, enforcing §2.6 zero-cleartext:

Key derivation — BLAKE3(context || local_wire || neighbor_wire || shared_secret). Domain-separated with "PlenumNET-CON-v2.3". Each of the 54 possible links gets its own derived key pair.
Directional keys — derive_tunnel_key(A, B) ≠ derive_tunnel_key(B, A). Canonical ordering via derive_link_keys() ensures both ends compute the same pair regardless of who initiates.
ConNode — Per-node tunnel manager. establish_tunnel() creates a link with derived key pair. establish_from_neighbor_map() bulk-creates tunnels for all geometric neighbors. mark_down()/mark_active() for FTS integration.
Key rotation — rekey_all() increments key epoch, derives new keys by appending epoch to shared secret. In production, TL-KEM replaces this with PQ key exchange.
Traffic accounting — Per-link byte counters (sent/received). total_bytes() aggregates.
Type-system enforcement of §2.6 — There is no send_plaintext() method. The only way to transmit data is through a TunnelLink with derived keys. Zero cleartext by construction.

bridge.rs (444 lines, 7 tests) — Metatronic Bridge
.plm → TDNS. Everything else → legacy DNS. Per §12.5:

resolve() — Single entry point. Checks TLD, routes to resolve_tdns() or resolve_legacy().
.plm detection — is_plm_name(): strict TLD match, not substring. plm.example.com routes to legacy DNS. example.plm routes to TDNS.
TDNS path — CRS lookup → time-lock validity check → drift redirect check → return 27-trit address. Three possible outcomes: Tdns (resolved), TdnsRedirect (drifted), Failed (not found or outside validity window).
Legacy path — System DNS resolution via ToSocketAddrs → IP addresses. Cached with configurable TTL (default 60s). Cache hit skips DNS. purge_cache() and clear_cache() for management.
Name utilities — extract_zone("pptpro.capomastro.plm") → "capomastro.plm". extract_label("pptpro.capomastro.plm") → "pptpro".
