T-19: key_rotation.rs — 629 lines, 14 tests
Orchestrates master secret rotation at arc epoch boundaries.
The Flow
check_and_rotate(unix_timestamp)
    │
    ├─ Rate limit: skip if checked < 60s ago
    ├─ check_dual_accept(): close expired window
    ├─ rotation_due_with_jitter(epoch, addr, ts)?
    │   └─ effective_time = epoch_boundary + per-node jitter
    │
    ├─ MasterSecret::generate()
    ├─ encrypt_master_secret(new, passphrase)
    ├─ rotation.rotate(new, epoch, ts)
    │   └─ current → previous, new → current
    ├─ pending_reregistration = true
    └─ Return RotationEvent
Jitter — Prevents Thundering Herd
jitter = TLSponge-385("PlenumNET-ROT-JITTER", addr_bytes) → ±6 hours
effective_rotation = epoch_boundary + jitter
Each node rotates at a deterministic but unique time. Same address always gets the same jitter — predictable for debugging, spread for load balancing.
