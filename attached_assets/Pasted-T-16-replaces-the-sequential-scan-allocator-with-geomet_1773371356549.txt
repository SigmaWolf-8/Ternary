```
### `placement.rs` — 833 lines, 23 tests

**Replaces sequential scan with geometry-aware placement.**

#### The Algorithm
```
allocate_optimal(registered, bitmap, density, seed):
  1. Cold start (< 3 nodes)?
     → Return predefined corner addresses (max mutual distance = 13)
  
  2. Generate candidates (up to 1,000):
     a. Unregistered neighbors of existing nodes (high-value: instant K≥1)
     b. Address from least-populated dimension values
     c. Deterministic pseudo-random via TLSponge-385
  
  3. Score each candidate:
     Primary:   max(min Hamming distance to all registered)
     Secondary: max(average Hamming distance)
     Tertiary:  min(imbalance score — prefer sparse regions)
  
  4. Filter by K-floor (K=2):
     Candidate must have ≥2 registered neighbors
     Fallback: relax to K=0 if no candidate meets floor
  
  5. Return (address, PlacementMetrics)
```

#### Cold Start — Maximally Separated Corners

| Node # | Address | Distance to previous |
|---|---|---|
| 0 | `[1,1,1,...,1]` | — (first node) |
| 1 | `[3,3,3,...,3]` | 13 (max possible) |
| 2 | `[2,2,2,...,2]` | 13 from both |
| 3+ | Max-spread algorithm | Computed |

All three cold start addresses are at mutual Hamming distance 13 — the maximum in a 13D space. This gives the widest possible initial spread.

#### DimensionDensity — 13×3 Tracker
```
     val=1  val=2  val=3
dim0 [  3,     1,     0  ]  ← dim 0 is heavy on val=1
dim1 [  1,     2,     1  ]
...
dim12[ 0,     0,     4  ]  ← dim 12 is heavy on val=3
imbalance_score(candidate) sums the counts for each dimension-value in the candidate. A candidate in sparse regions scores low → preferred by the tertiary sort.
least_populated_value(dim) returns the trit value with the fewest registered nodes in that dimension — used to construct a "maximally sparse" candidate address.
Candidate Generation Strategy

Neighbor expansion (50% of budget): Unregistered neighbors of existing nodes. These automatically have ≥1 registered neighbor, making K-floor easier to satisfy.
Least-populated construction: One address built from least_populated_value(dim) for each dimension.
Pseudo-random samples: TLSponge-385 seeded deterministically to fill remaining budget.
