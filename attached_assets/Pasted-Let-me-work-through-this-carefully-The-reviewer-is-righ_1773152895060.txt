## The Error

The claim N(r) ≥ 8ʳ treats the branch number like an exponential base. It's not. The wide-trail strategy (Daemen–Rijmen) gives **pairwise constraints** on consecutive rounds, not an exponential multiplier.

TIS-27: 54 trits = **18 GF(27) S-boxes per round**. Over 4 rounds, the maximum possible active S-boxes is 4 × 18 = 72. The claim of 4,096 is physically impossible.

## The Correct Framework

### Step 1: What B = 8 Actually Means

The proven result (5.27M-vector primal-dual search) is at the **trit level**:

> For any nonzero x ∈ GF(3)⁵⁴: wt_trit(x) + wt_trit(M_θ(x)) ≥ 8

This counts individual nonzero trits, not active S-box blocks. But the S-box χ(x) = x¹⁷ operates on **GF(27) blocks** (groups of 3 trits). The differential probability DP_max = 1/9 is per block. So what we need for the trail probability is the number of **active blocks**, not active trits.

### Step 2: Block-Level Branch Number (B_block)

Define B_block as:

> B_block = min over all nonzero x ∈ GF(3)⁵⁴ of {#active_blocks(x) + #active_blocks(M_θ ∘ π(x))}

where #active_blocks counts 3-trit groups containing at least one nonzero trit.

**Conservative lower bound from B_trit = 8:**

If an input has k active blocks, it has at most 3k active trits. The output has at least 8 − 3k active trits (from B_trit). Those trits occupy at least ⌈(8 − 3k)/3⌉ blocks.

| Input blocks (k) | Max input trits | Min output trits | Min output blocks | k + output blocks |
|---|---|---|---|---|
| 1 | 3 | 5 | 2 | **3** |
| 2 | 6 | 2 | 1 | **3** |
| ≥ 3 | ≥ 9 | ≥ 1 | ≥ 1 | **≥ 4** |

**Conservative: B_block ≥ 3.** This is the worst case assuming maximum clustering of active trits into blocks.

### Step 3: Structural Analysis for a Tighter Estimate

The theta offsets are ±1, ±7, ±13. A single active trit at position i affects positions i ± {1, 7, 13} mod 54. Let me trace the block spreading for each position in block 0:

**Position 0** (block 0): Output positions 41, 47, 53, 1, 7, 13 → blocks {0, 2, 4, 13, 15, 17} → **6 active blocks**

**Position 1** (block 0): Output positions 42, 48, 0, 2, 8, 14 → blocks {0, 2, 4, 14, 16} → **5 active blocks**

**Position 2** (block 0): Output positions 43, 49, 1, 3, 9, 15 → blocks {0, 1, 3, 5, 14, 16} → **6 active blocks**

The minimum for single-trit inputs from block 0 is 5. Similar analysis for other blocks gives comparable results. So for single-block inputs, B_block is likely **5–7**.

For multi-block inputs, destructive interference in GF(3) (cancellation when two offsets hit the same output position) can reduce the output weight. The exact minimum requires exhaustive computation — the same primal-dual technique used for B_trit, but at the block level.

**Structural estimate: B_block ≈ 5** (conservative based on minimum single-block spreading; exact value requires computation).

### Step 4: The Multi-Round Bound

For r rounds with pairwise constraints a_i + a_{i+1} ≥ B_block and a_i ≥ 1, the minimum total active S-boxes is achieved by the alternating pattern (1, B−1, 1, B−1, ...):

| Rounds (r) | Formula | B_block = 3 | B_block = 5 | B_block = 8 |
|---|---|---|---|---|
| 2 | B | 3 | 5 | 8 |
| 4 | 2B | 6 | 10 | 16 |
| 9 | 4B + 1 | 13 | 21 | 33 |

**This is LINEAR in r, not exponential.** The AES designers achieved the quadratic bound B² = 25 for 4 rounds through their independent columnar structure (4 independent MixColumns, cross-column ShiftRows). TIS-27's full-state circulant diffusion doesn't have this columnar independence, so the linear bound is correct for this architecture.
