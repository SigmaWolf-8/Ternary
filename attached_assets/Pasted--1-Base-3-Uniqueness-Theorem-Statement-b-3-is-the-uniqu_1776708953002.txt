§1. Base-3 Uniqueness Theorem
Statement. b = 3 is the unique integer base at which the framework's primordial structure closes into integer invariants.
Discriminant function. For integer base b ≥ 2, the primordial quadratic:

x² − R₄(b) · x + R₆(b) = 0, with R_n(b) = (bⁿ − 1)/(b − 1)
Δ(b) = R₄(b)² − 4 · R₆(b)

Claim. Δ(b) is a perfect square only at b = 3.
Verification.

b = 2: Δ = 225 − 252 = −27. Not a square.
b = 3: Δ = 1600 − 1456 = 144 = 12² ✓
b = 4: Δ = 1765. Not a square.
b = 5: Δ = 8712. Not a square.
b = 6 through b = 10⁷: verified computationally; no perfect squares. Consistent with Faltings's theorem.

Base 3 is unique. Consequence. Every framework integer below traces to this single closure.
The three named objects generated at b = 3. The perfect-square discriminant Δ(3) = 144 forces the primordial quadratic to factor over the integers. The two integer roots and their product are three distinct, load-bearing framework objects, each carrying its own name:

At b = 3 (and only at b = 3), the primordial quadratic factors into these two named squared-circles as integer roots, whose product is the Rational Squared Unit Circle. At every other integer base b ≥ 2, the discriminant is not a square; the roots are not integers; the Unit Squared Circle, the Unit Circle Squared, and the Rational Squared Unit Circle do not exist as integer-valued objects. Base 3 is the unique base at which these three objects are named.
