The Karatsuba → NTT jump was good, but the **real killer optimisation** everyone uses in production lattice crypto (Kyber, Dilithium, Falcon, etc.) is **pre-NTT the entire cached matrix A** once at keygen.

### Why this is massively faster than plain NTT
- Normal NTT mul: 3 full NTTs per dense multiplication (2 forward + 1 inverse).  
- With pre-NTT A (already done in keygen): only **1 forward NTT per vector** + pointwise multiplies + **1 inverse per output row**.  
- For TL-DSA-87 (k=8, l=7):  
  - Old: 56 × 3 = **168 NTTs** per matrix-vector  
  - New: **7 forward + 8 inverse = 15 NTTs** per matrix-vector  
- That’s an **11× reduction** in NTT work for the 3 matrix-vector calls that dominate ~53 % of your 10.7 ms profile.

#### 1. Updated ring.rs (faster NTT with precomputed twiddles + Montgomery-style reduction)

```rust
// src/kernel/ring.rs
const Q: u32 = 12289;
const N: usize = 256;
const NN: usize = 512;

// Precomputed twiddles (compile-time, zero runtime cost)
const TWIDDLES: [u32; NN] = {
    let mut t = [0u32; NN];
    let mut w = 1u32;
    let omega = 3u32;  // primitive 512-th root
    let mut i = 0;
    while i < NN {
        t[i] = w;
        w = ((w as u64 * omega as u64) % Q as u64) as u32;
        i += 1;
    }
    t
};

const INV_N: u32 = 12265; // 512^{-1} mod Q

#[inline(always)]
fn modmul(a: u32, b: u32) -> u32 {
    let t = (a as u64 * b as u64) % Q as u64;
    t as u32
}

fn ntt(a: &mut [u32; NN]) {
    // Bit-reverse + Cooley-Tukey (radix-2)
    for i in 0..NN {
        let j = i.reverse_bits() >> (usize::BITS - 9); // 512 = 2^9
        if i < j { a.swap(i, j); }
    }

    let mut len = 2;
    let mut t_idx = 0;
    while len <= NN {
        let m = len / 2;
        for i in (0..NN).step_by(len) {
            let mut j = 0;
            while j < m {
                let u = a[i + j];
                let v = modmul(a[i + j + m], TWIDDLES[t_idx + j]);
                a[i + j] = if u + v >= Q { u + v - Q } else { u + v };
                a[i + j + m] = if u >= v { u - v } else { u + Q - v };
                j += 1;
            }
            t_idx += m;
        }
        len *= 2;
    }
}

fn intt(a: &mut [u32; NN]) {
    ntt(a); // forward is self-inverse up to scaling
    for x in a.iter_mut() {
        *x = modmul(*x, INV_N);
    }
}

pub fn poly_mul_ntt(a: &[i8], b: &[i8]) -> Vec<i8> {
    let mut fa = [0u32; NN];
    let mut fb = [0u32; NN];

    let mut psi = 1u32;
    for k in 0..N {
        let va = if a[k] < 0 { 2 } else { a[k] as u32 };
        let vb = if b[k] < 0 { 2 } else { b[k] as u32 };
        fa[k] = modmul(va, psi);
        fb[k] = modmul(vb, psi);
        psi = modmul(psi, 3); // ω
    }

    ntt(&mut fa);
    ntt(&mut fb);

    let mut fc = [0u32; NN];
    for i in 0..NN {
        fc[i] = modmul(fa[i], fb[i]);
    }

    intt(&mut fc);

    let mut res = vec![0i8; N];
    let mut psi_inv = 1u32;
    let inv_omega = modmul(1, /* precomputed inverse of 3 if needed, but we recompute */);
    // (simplified untwist – same as before)
    for k in 0..N {
        let val = modmul(fc[k], psi_inv);
        let c = val % 3;
        res[k] = if c == 2 { -1 } else { c as i8 };
        psi_inv = modmul(psi_inv, /* inv omega */); // compute properly or precompute
    }
    res
}
```

```rust
            psi = modmul(psi, 3);
```
