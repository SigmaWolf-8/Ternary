## SUMMARY

You are building a **standards-compliant RFC 3161 Time-Stamping Authority** — a "Digital Notary for the Digital Age" — inside PlenumNET. This is the 21st Kong service, sitting alongside timing (`/api/salvi/timing/*`), PQTI signing (`/api/pqti/*`), and the notification service (`/api/notify/*`).

From the PlenumNET white paper:

> *"A Time-Stamping Authority performs an analogous function [to a traditional notary] for digital data. Because even a single-bit change in the original data produces a completely different hash, the TST serves as irrefutable evidence of integrity and existence-at-time. The TSA never sees the original data — a privacy-by-design principle critical for law firms, banks, and government agencies handling sensitive information."*

The service implements a four-step exchange:

| Step | Action | Implementation |
|------|--------|----------------|
| 1. Hash | Client computes cryptographic hash of data | Client-side (we never see original data) |
| 2. Submit | Client sends only the hash to TSA | `POST /api/tsa/timestamp` or `/api/tsa/timestamp/json` |
| 3. Bind | TSA binds hash to trusted time + signs | HPTP engine + RSA-4096 + TL-DSA dual-sign |
| 4. Return | TSA returns Time-Stamp Token (TST) | ASN.1 DER or JSON-wrapped base64 token |

Four tiered policies encoded as distinct OIDs per white paper §8:
- **COMPLY** — Financial compliance (FINRA Rule 613, Consolidated Audit Trail)
- **FORENSICS** — Legal evidence, eDiscovery, Digital Evidence Vaults
- **SENTINEL** — Government/military, ordering guaranteed, timeline reconstruction
- **SECURE** — Enterprise Zero-Trust (ZTNA), Secure Collaboration Enclaves

Multiple Capomastro applications (Maestro ERP, Sign Here, PPTPro) and external clients (OpenSSL, Adobe Acrobat, jarsigner, Authenticode) will call this service.

**You build 2 new files and modify 2 existing files.** All code is provided below.

// ============================================================================
// MERKLE TREE AUDIT LOG — White Paper §9.3
//
// "Events are recorded in a Merkle tree, with each leaf timestamped
// according to RFC 3161."
//
// Every token's serial + hash + genTime forms a leaf. The tree provides
// tamper-evident proof that the audit log hasn't been modified after the
// fact. Attackers cannot remove or reorder entries without invalidating
// the root hash.
// ============================================================================

class MerkleAuditLog {
  private leaves: string[] = [];
  private persistPath: string;

  constructor(keysDirectory: string) {
    this.persistPath = path.join(keysDirectory, 'merkle-leaves.jsonl');
    this.loadFromDisk();
  }

  /** Restore leaves from JSONL file on startup (survives restarts) */
  private loadFromDisk(): void {
    if (fs.existsSync(this.persistPath)) {
      const lines = fs.readFileSync(this.persistPath, 'utf8').split('\n').filter(Boolean);
      this.leaves = lines.map(line => {
        try { return JSON.parse(line).hash; }
        catch { return ''; }
      }).filter(Boolean);
      console.log(`Merkle audit log restored: ${this.leaves.length} leaves from ${this.persistPath}`);
    }
  }

  /** Add a leaf, persist to disk, return leaf hash */
  addLeaf(serialNumber: string, hashedMessage: string, genTime: string): string {
    const leafData = `${serialNumber}|${hashedMessage}|${genTime}`;
    const leafHash = crypto.createHash('sha3-256').update(leafData).digest('hex');
    this.leaves.push(leafHash);
    // Append-only persistence — one JSON line per leaf
    fs.appendFileSync(this.persistPath,
      JSON.stringify({ serial: serialNumber, hash: leafHash, ts: genTime }) + '\n');
    return leafHash;
  }

  getRoot(): string {
    if (this.leaves.length === 0) {
      return crypto.createHash('sha3-256').update('empty-tree').digest('hex');
    }
    let level = [...this.leaves];
    while (level.length > 1) {
      const next: string[] = [];
      for (let i = 0; i < level.length; i += 2) {
        const left = level[i];
        const right = level[i + 1] || left;
        next.push(crypto.createHash('sha3-256').update(left + right).digest('hex'));
      }
      level = next;
    }
    return level[0];
  }

  getDepth(): number {
    if (this.leaves.length === 0) return 0;
    return Math.ceil(Math.log2(this.leaves.length)) + 1;
  }

  getSize(): number { return this.leaves.length; }
}

export class TsaService {
  private config: TsaConfig;
  private hptpClient: HptpClient;
  private tldsaClient: TldsaClient;
  private privateKey: crypto.KeyObject | null = null;
  private certificate: Buffer | null = null;
  private certificateParsed: crypto.X509Certificate | null = null;
  private serialCounter: bigint = BigInt(0);
  private tokenLog: TsaTokenRecord[] = [];
  private merkleLog!: MerkleAuditLog; // initialized in initialize()
  private startTime: number = Date.now();

  constructor(config: TsaConfig, hptpClient: HptpClient, tldsaClient: TldsaClient) {
    this.config = config;
    this.hptpClient = hptpClient;
    this.tldsaClient = tldsaClient;
  }

  // --------------------------------------------------------------------------
  // INITIALIZATION — Load keys, verify cert, restore serial counter
  //
  // White paper §9.4: "All timestamping keys reside in FIPS 140-2 Level 3
  // HSMs that are physically and logically protected."
  // CURRENT: Software key store. PRODUCTION: Migrate to HSM.
  // --------------------------------------------------------------------------

  async initialize(): Promise<{
    success: boolean;
    keyLoaded: boolean;
    certValid: boolean;
    certExpiry: string;
    certSubject: string;
    serialRestored: string;
  }> {
    if (!fs.existsSync(this.config.keysDirectory)) {
      fs.mkdirSync(this.config.keysDirectory, { recursive: true });
    }

    if (!fs.existsSync(this.config.privateKeyPath)) {
      this.generateTsaKeyPair();
    }

    const keyPem = fs.readFileSync(this.config.privateKeyPath, 'utf8');
    this.privateKey = crypto.createPrivateKey(keyPem);

    const certPem = fs.readFileSync(this.config.certificatePath, 'utf8');
    this.certificate = Buffer.from(
      certPem.replace(/-----BEGIN CERTIFICATE-----/g, '')
        .replace(/-----END CERTIFICATE-----/g, '')
        .replace(/\s/g, ''),
      'base64',
    );
    this.certificateParsed = new crypto.X509Certificate(certPem);

    const counterPath = path.join(this.config.keysDirectory, 'serial-counter.txt');
    if (fs.existsSync(counterPath)) {
      this.serialCounter = BigInt(fs.readFileSync(counterPath, 'utf8').trim());
    }

    // Initialize Merkle audit log with disk persistence
    this.merkleLog = new MerkleAuditLog(this.config.keysDirectory);

    return {
      success: true,
      keyLoaded: this.privateKey !== null,
      certValid: this.isCertificateValid(),
      certExpiry: this.certificateParsed?.validTo || 'unknown',
      certSubject: this.certificateParsed?.subject || 'unknown',
      serialRestored: this.serialCounter.toString(),
    };
  }

  // --------------------------------------------------------------------------
  // CORE: RFC 3161 Binary Endpoint
  //
  // White paper §4: "RFC 3161 defines a two-message transaction between
  // a client and a TSA. The messages are formally specified in ASN.1,
  // ensuring interoperability across all compliant implementations worldwide."
  //
  // This is what OpenSSL, Adobe Acrobat, jarsigner, and Authenticode call.
  // --------------------------------------------------------------------------

  async processTimestampRequest(derRequest: Buffer, requestIp: string): Promise<Buffer> {
    // Step 1: Parse TimeStampReq (white paper §4.1)
    let parsed: {
      version: number;
      hashAlgorithmOid: string;
      hashedMessage: Buffer;
      reqPolicy: string | null;
      nonce: bigint | null;
      certReq: boolean;
    };
    try {
      parsed = this.parseTimeStampReq(derRequest);
    } catch (error) {
      return this.buildErrorResponse(2, `Bad request: ${(error as Error).message}`);
    }

    // Step 2: Validate hash algorithm (§9.1 quantum-safe readiness)
    const hashAlgName = HASH_ALGORITHM_OIDS[parsed.hashAlgorithmOid];
    if (!hashAlgName) {
      return this.buildErrorResponse(2, `Unsupported hash algorithm: ${parsed.hashAlgorithmOid}`);
    }

    // Step 3: Resolve policy tier (white paper §8)
    const policyOid = parsed.reqPolicy || this.config.defaultPolicy;
    const policyMeta = TSA_POLICY_METADATA[policyOid];
    if (!policyMeta) {
      return this.buildErrorResponse(2, `Unknown policy: ${policyOid}`);
    }

    // Step 4: Get trusted time from HPTP (white paper §9.2, §9.5)
    // "Distributed mesh of GPS/GNSS receivers + atomic clock backup,
    // hardened against jamming and spoofing."
    let hptpResult: { timestamp: string; precision: string; source: string };
    try {
      hptpResult = await this.hptpClient.getTimestamp();
    } catch {
      // White paper §9.5: system clock only as absolute last resort
      hptpResult = {
        timestamp: new Date().toISOString(),
        precision: 'millisecond-fallback',
        source: 'system-clock',
      };
    }

    // Step 5: Monotonic serial number (white paper §6 row 3: "Integrated
    // with Immutable Audit Log API; each serial is part of tamper-proof Merkle tree")
    const serialNumber = this.nextSerialNumber();

    // Step 6: Build TSTInfo (white paper §5 enhancement table)
    //
    // ACCURACY CLAMPING — RFC 3161 Accuracy type constraint:
    //   Accuracy ::= SEQUENCE { seconds INTEGER OPTIONAL,
    //     millis [0] INTEGER (1..999) OPTIONAL,
    //     micros [1] INTEGER (1..999) OPTIONAL }
    // The micros field CANNOT exceed 999. Clamp to RFC max if policy
    // declares higher. Full HPTP native precision is logged separately
    // in extended metadata (JSON API, audit log, health) for internal/
    // forensic use — this satisfies FINRA CAT nanosecond truncation
    // needs while keeping the ASN.1 wire format strictly compliant.
    const declaredAccuracy = {
      seconds: policyMeta.accuracySeconds,
      micros: Math.min(policyMeta.accuracyMicros, 999),
    };

      console.warn(`TSA: Policy ${policyMeta.tier} accuracy ${policyMeta.accuracyMicros}µs exceeds RFC max; clamped to 999µs in token`);
    }

    const tstInfo = this.buildTSTInfo({
      serialNumber,
      genTime,
      hashAlgorithmOid: parsed.hashAlgorithmOid,
      hashedMessage: parsed.hashedMessage,
      policyOid,

      accuracy: declaredAccuracy,
      ordering: policyMeta.orderingGuaranteed,

    // be verified decades later, even against quantum adversaries."

        const tstHash = crypto.createHash('sha3-256').update(tstInfo).digest('hex');
        const result = await this.tldsaClient.sign(tstHash);
        tldsaSig = { signature: result.signature, publicKeyId: result.publicKeyId };
      } catch {
        // Classical RSA is sufficient; TL-DSA is best-effort
      }
    }

    // Step 10: Build TimeStampResp (white paper §4.2)
    const response = this.buildTimeStampResp(0, timeStampToken);

    // Step 11: Merkle audit log (white paper §9.3)

      serialNumber.toString(),
      parsed.hashedMessage.toString('hex'),
      genTime,
    );

      serialNumber: serialNumber.toString(),
      genTime,
      genTimeHptp: hptpResult.timestamp,
      hptpPrecision: hptpResult.precision,
      hptpSource: hptpResult.source,

      hashedMessage: parsed.hashedMessage.toString('hex'),
      policyOid,
      policyTier: policyMeta.tier,

      ordering: policyMeta.orderingGuaranteed,
      requestIp,

      tldsaSignature: tldsaSig?.signature || null,
      tldsaKeyId: tldsaSig?.publicKeyId || null,

interface AuthenticatedRequest extends Request {
  auth?: { appId: string; role: 'admin' | 'app' | 'readonly' };
}

function requireAuth(minRole: 'readonly' | 'app' | 'admin') {
  const hierarchy = { readonly: 0, app: 1, admin: 2 };
  return (req: AuthenticatedRequest, res: Response, next: NextFunction) => {
    const authHeader = req.headers.authorization;
    if (!authHeader) return res.status(401).json({ error: 'Authentication required' });
    try {
      const token = authHeader.replace('Bearer ', '');
      const payload = JSON.parse(Buffer.from(token.split('.')[1] || token, 'base64').toString());
      const auth = { appId: payload.appId || 'unknown', role: (payload.role || 'readonly') as 'admin' | 'app' | 'readonly' };
      if (hierarchy[auth.role] < hierarchy[minRole]) return res.status(403).json({ error: 'Insufficient permissions' });
      req.auth = auth;
      next();
    } catch { return res.status(401).json({ error: 'Invalid authentication token' }); }
  };
}

              policy: `OID. DEFAULT=${TSA_POLICIES.DEFAULT}, COMPLY=${TSA_POLICIES.COMPLY}, FORENSICS=${TSA_POLICIES.FORENSICS}, SENTINEL=${TSA_POLICIES.SENTINEL}, SECURE=${TSA_POLICIES.SECURE}`,
              nonce: 'hex-encoded nonce for replay protection',
              includeChain: 'boolean — include TSA certificate chain',
            },
          });
        }
        const result = await service.processJsonRequest(
          { hash, algorithm, policy, nonce, includeChain }, req.ip || 'unknown',
        );
        res.status(200).json({ success: true, ...result, callerApp: req.auth?.appId });
      } catch (error) { res.status(422).json({ success: false, error: (error as Error).message }); }
    },
  );

  // POST /api/tsa/verify — UNAUTHENTICATED (white paper §7)
  router.post('/verify', async (req: Request, res: Response) => {
    try {
      let derToken: Buffer;
      if (req.headers['content-type'] === 'application/timestamp-reply') {
        derToken = Buffer.isBuffer(req.body) ? req.body : Buffer.from(req.body);
      } else if (req.body?.token) {
        derToken = Buffer.from(req.body.token, 'base64');
      } else {
        return res.status(400).json({ error: 'Provide binary timestamp-reply or JSON { token: "base64" }' });
      }
      res.status(200).json(await service.verifyToken(derToken));
    } catch (error) { res.status(422).json({ valid: false, error: (error as Error).message }); }
  });

  // GET /api/tsa/certificate — UNAUTHENTICATED
  router.get('/certificate', (_req: Request, res: Response) => {
    try { res.status(200).json(service.getTsaCertificate()); }
    catch (error) { res.status(500).json({ error: (error as Error).message }); }
  });

  // GET /api/tsa/certificate/download — UNAUTHENTICATED
  router.get('/certificate/download', (_req: Request, res: Response) => {
    try {
      const cert = service.getTsaCertificate();
      res.status(200)
        .set('Content-Type', 'application/x-pem-file')
        .set('Content-Disposition', 'attachment; filename="plenumnet-tsa.pem"')
        .send(cert.certificate);
    } catch (error) { res.status(500).json({ error: (error as Error).message }); }
  });

  // GET /api/tsa/tokens — ADMIN ONLY (audit log)
  router.get('/tokens', requireAuth('admin'),
    (req: AuthenticatedRequest, res: Response) => {
      res.status(200).json(service.queryTokenLog({
        since: req.query.since as string, until: req.query.until as string,
        hashAlgorithm: req.query.hashAlgorithm as string,
        policyTier: req.query.policyTier as string,
        limit: req.query.limit ? parseInt(req.query.limit as string) : undefined,
      }));
    },
  );

  // GET /api/tsa/policy — UNAUTHENTICATED (white paper §9.6)
  router.get('/policy', (_req: Request, res: Response) => {
    res.status(200).json(service.getPolicyInfo());
  });

  // GET /api/tsa/health — UNAUTHENTICATED
  router.get('/health', async (_req: Request, res: Response) => {
    const health = await service.getHealth();
    res.status(health.status === 'unhealthy' ? 503 : 200).json(health);
  });

  return router;
}

}

// Raw body parsing for RFC 3161 binary requests
// MUST come BEFORE json parser for this path
// 64KB cap — a valid TimeStampReq is typically <1KB; anything larger is malformed or malicious
const TSA_MAX_BODY_BYTES = 65536;
app.use('/api/tsa/timestamp', (req, _res, next) => {
  if (req.headers['content-type'] === 'application/timestamp-query') {
    const chunks: Buffer[] = [];
    let totalBytes = 0;
    req.on('data', (chunk: Buffer) => {
      totalBytes += chunk.length;
      if (totalBytes > TSA_MAX_BODY_BYTES) {
        req.destroy(new Error(`Request body exceeds ${TSA_MAX_BODY_BYTES} bytes`));
        return;
      }
      chunks.push(chunk);
    });
    req.on('end', () => { req.body = Buffer.concat(chunks); next(); });
  } else { next(); }
});

## NON-NEGOTIABLE RULES

1. **TSA private key is EXCLUSIVELY for timestamping.** RFC 3161 §5 + white paper §6 row 5. EKU marked critical. Never reuse.
2. **Serial numbers never repeat, never go backwards.** Persist to disk after every increment.
3. **HPTP is the time source.** System clock only as absolute last resort, and mark the token accordingly.
4. **TL-DSA is best-effort.** Classical RSA signature is primary and sufficient.
5. **Privacy-by-design.** The TSA never receives, stores, or processes original data. Only hashes. (White paper §3)
6. **Certificate, verify, and policy endpoints are unauthenticated.** Verifiers need these without credentials.
7. **All code stays in the Ternary repo.** Kong service #21.
