### 🔴 Priority 1 — Quick Wins (Same Session)

**1. Fix the Long-Lived Session Cookie (D24 → Security Finding)**

In your Express/server config, set cookie `maxAge` to ≤30 days:
```js
// server/index.ts or wherever sessions are configured
cookie: {
  maxAge: 30 * 24 * 60 * 60 * 1000, // 30 days exactly
  httpOnly: true,
  secure: true,
  sameSite: 'strict'
}
```
This clears the only active Security Finding and improves D24 from `Long-lived` (T3) to `Session` (T1).

---

**2. Add Missing Security Headers (D25, D13 — 6 missing headers)**

In Replit, add a `_headers` file at the project root (Replit serves this statically) **or** inject them via your Express middleware:

```js
// server/middleware/securityHeaders.ts
app.use((req, res, next) => {
  res.setHeader('X-Frame-Options', 'DENY');
  res.setHeader('Permissions-Policy', 'camera=(), microphone=(), geolocation=()');
  res.setHeader('Cross-Origin-Opener-Policy', 'same-origin');
  res.setHeader('Cross-Origin-Embedder-Policy', 'require-corp');
  res.setHeader('NEL', JSON.stringify({
    report_to: "default",
    max_age: 86400,
    include_subdomains: true
  }));
  res.setHeader('Report-To', JSON.stringify({
    group: "default",
    max_age: 86400,
    endpoints: [{ url: "/api/csp-reports" }]
  }));
  next();
});
```

This directly lifts D25 (Encryption posture already Hardened TLS — these complete the suite) and D13 signals.
