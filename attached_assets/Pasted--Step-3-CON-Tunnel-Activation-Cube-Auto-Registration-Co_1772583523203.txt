#    Uses rustls (pure Rust) to avoid OpenSSL dev header issues.
#
# 2. main.rs — Dual-mode daemon (447 → 709 lines):
#
#    CRS MODE (CUBE_MODE=crs):
#    - Same as before: allocates self, serves full 11-route API
#    - NEW: Logs each cube registration with address and endpoint
#
#    CUBE MODE (CUBE_MODE=cube):
#    - On boot, derives unique BLAKE3 public key from endpoint
#    - POSTs to CRS /register endpoint (retries up to 10x)
#    - Gets unique address assigned by CRS
#    - Resolves registered neighbors from CRS response
#    - Initializes local CON → FTS → GLB pipeline
#    - Spawns background heartbeat task (every 30s to CRS)
#    - Runs local HTTP server with 8 status routes
