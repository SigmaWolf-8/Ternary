# Task #102 — Buried Question Engine: Coprime, Sparse & gf3_algebra Completion

## Updated with all review findings (v4 — April 2026)

## What & Why

Build the two shared foundation modules (coprime.rs, sparse.rs) and add three missing utility functions to gf3_algebra.rs. These are the primitives the Buried Question Compression Engine and the Coprime Index (TM-2026-028a) require.

**TritInt is the gate.** Every public function in coprime.rs and sparse.rs takes and returns TritInt. No u64 in any public signature. Legacy binary code converts at ITS gate via `TritInt::from_u64()`, not ours.

**coprime.rs does NOT re-export TritInt methods.** `TritInt::gcd`, `TritInt::div_mod`, `TritInt::mul` already exist (Phases 1-6). coprime.rs provides HIGHER-LEVEL operations built on these: coprimality predicates, walks, combinations, totient, and standalone CRT. Things that don't belong on the storage primitive.

**Two internal boundary crossings are acceptable (host bookkeeping):**
- Loop counts: `n.to_decimal() as usize` for `for _ in 0..n` — host control flow, not a mathematical value. Same justification as `trit_count: u32` in TritIntStorage.
- SparseMap HashMap key: `u64` encoding of coordinates — host data structure key. Public API is TritInt. Internal encoding is host bookkeeping.

**2. `euler_totient`**
```rust
/// Euler's totient φ(n) via trial division in TritInt arithmetic.
/// Matches the approach at coprime_polygon_pair.rs:125-133.
pub fn euler_totient(n: &TritInt) -> TritInt {
    let mut result = n.clone();
    let mut temp = n.clone();
    let one = TritInt::one();
    let mut p = TritInt::from_u64(2);
    loop {
        let p_sq = TritInt::mul(&p, &p);
        if p_sq > temp { break; }
        let (_, rem) = temp.div_mod(&p);
        if rem.is_zero() {
            loop {
                let (q, r) = temp.div_mod(&p);
                if r.is_zero() { temp = q; } else { break; }
            }
            let (quot, _) = result.div_mod(&p);
            result = TritInt::sub(&result, &quot);
        }
        p = TritInt::add(&p, &one);
    }
    if temp > one {
        let (quot, _) = result.div_mod(&temp);
        result = TritInt::sub(&result, &quot);
    }
    result
}
```

**3. `coprime_options`**

```rust
/// All values in [min, max] coprime to `axis`.
pub fn coprime_options(axis: &TritInt, min: &TritInt, max: &TritInt) -> Vec<TritInt> {
    let one = TritInt::one();
    let mut result = Vec::new();
    let mut val = min.clone();
    while val <= *max {
        if is_coprime(&val, axis) {
            result.push(val.clone());
        }
        val = TritInt::add(&val, &one);
    }
    result
}
```

**4. `coprime_walk`**
```rust
/// 2D coprime walk on Z_a × Z_b. Requires gcd(a,b) = 1.
/// Returns all a×b distinct (x mod a, y mod b) coordinate pairs.
///
/// Walk step: smallest integer ≥ 2 coprime to a×b. This spreads
/// adjacent walk positions apart on the torus (better entropy
/// distribution than step=1 sequential enumeration).
///
/// The step cannot be a or b (both divide a×b). For coprime_walk(11, 13),
/// step=2 (smallest coprime to 143). For custom generators per dimension,
/// use `multidim_walk`.
pub fn coprime_walk(a: &TritInt, b: &TritInt) -> Vec<(TritInt, TritInt)> {
    assert!(is_coprime(a, b), "coprime_walk requires gcd(a,b)=1");
    let n = TritInt::mul(a, b);
    let one = TritInt::one();
    let mut step = TritInt::from_u64(2);
    while !is_coprime(&step, &n) {
        step = TritInt::add(&step, &one);
    }
    let n_count = n.to_decimal() as usize; // host control flow
    let mut result = Vec::with_capacity(n_count);
    let mut pos = TritInt::zero();
    for _ in 0..n_count {
        let (_, x) = pos.div_mod(a);
        let (_, y) = pos.div_mod(b);
        result.push((x, y));
        pos = TritInt::add(&pos, &step);
    }
    result
}
```

**5. `coprime_combinations`**
```rust
/// Enumerate all maximal pairwise-coprime subsets of `moduli`.
/// Maximal = no element from `moduli` can be added without breaking
/// pairwise coprimality. Bounded: practical input size |moduli| ≤ ~15.
///
/// For the 13-polygon set, produces the four sextuples (TM-2026-028a §3.3):
/// {3,4,5,7,11,13}, {3,5,7,8,11,13}, {4,5,7,9,11,13}, {5,7,8,9,11,13}
pub fn coprime_combinations(moduli: &[TritInt]) -> Vec<Vec<TritInt>> {
    let mut results = Vec::new();
    let mut current = Vec::new();
    find_maximal(moduli, 0, &mut current, &mut results);
    results
}

fn find_maximal(
    moduli: &[TritInt], start: usize,
    current: &mut Vec<TritInt>, results: &mut Vec<Vec<TritInt>>
) {
    let mut extended = false;
    for i in start..moduli.len() {
        if current.iter().all(|c| is_coprime(c, &moduli[i])) {
            current.push(moduli[i].clone());
            find_maximal(moduli, i + 1, current, results);
            current.pop();
            extended = true;
        }
    }
    if !extended && !current.is_empty() {
        results.push(current.clone());
    }
}
```

**6. `multidim_walk`**
```rust
/// k-dimensional Hamiltonian cycle on Z_{m_1} × ... × Z_{m_k}.
/// Each generator[i] must be coprime to moduli[i].
/// Cycle length = product of all moduli.
/// Panics if lengths mismatch or any generator not coprime to its modulus.
pub fn multidim_walk(moduli: &[TritInt], generators: &[TritInt]) -> Vec<Vec<TritInt>> {
    assert_eq!(moduli.len(), generators.len());
    for i in 0..moduli.len() {
        assert!(is_coprime(&generators[i], &moduli[i]),
            "generator must be coprime to modulus");
    }
    let cycle_len: u64 = moduli.iter()
        .map(|m| m.to_decimal())  // host control flow
        .product();
    let k = moduli.len();
    let mut result = Vec::with_capacity(cycle_len as usize);
    let mut pos: Vec<TritInt> = vec![TritInt::zero(); k];
    for _ in 0..cycle_len {
        result.push(pos.clone());
        for j in 0..k {
            let sum = TritInt::add(&pos[j], &generators[j]);
            let (_, rem) = sum.div_mod(&moduli[j]);
            pos[j] = rem;
        }
    }
    result
}
```

**7. `crt_combine`**
```rust
/// CRT combination: given residues and pairwise-coprime moduli, recover
/// the unique value in [0, product(moduli)) that produces those residues.
///
/// This is the mathematical operation behind both the AGS crt_reconstruct
/// and the Coprime Index (TM-2026-028a). Standalone version — not tied
/// to the dynamic AGS generator set.
///
/// Panics if moduli are not pairwise coprime.
pub fn crt_combine(residues: &[TritInt], moduli: &[TritInt]) -> TritInt {
    assert_eq!(residues.len(), moduli.len());
    // Verify pairwise coprimality
    for i in 0..moduli.len() {
        for j in (i+1)..moduli.len() {
            assert!(is_coprime(&moduli[i], &moduli[j]),
                "crt_combine requires pairwise coprime moduli");
        }
    }

    // Successive substitution (Garner's algorithm)
    let mut result = residues[0].clone();
    let mut product = moduli[0].clone();

    for i in 1..moduli.len() {
        let (_, a, _) = TritInt::extended_gcd(&product, &moduli[i]);
        let diff = if residues[i] >= result {
            TritInt::sub(&residues[i], &result)
        } else {
            TritInt::sub(&moduli[i], &TritInt::sub(&result, &residues[i]))
        };
        let step = TritInt::mul(&a, &diff).div_mod(&moduli[i]).1;
        result = TritInt::add(&result, &TritInt::mul(&product, &step));
        product = TritInt::mul(&product, &moduli[i]);
    }

    result.div_mod(&product).1
}
```

**8. `crt_split`**
```rust
/// CRT decomposition: split a value into its residues mod each modulus.
/// Inverse of crt_combine: crt_combine(crt_split(v, m), m) == v for v < product(m).
pub fn crt_split(value: &TritInt, moduli: &[TritInt]) -> Vec<TritInt> {
    moduli.iter().map(|m| value.div_mod(m).1).collect()
}
```

### SparseMap — TritInt moduli, mixed-radix u64 key encoding:

```rust
/// Sparse map for torus cell data.
///
/// Stores only occupied cells. Coordinates are TritInt values bounded
/// by moduli. Internally encoded as mixed-radix u64 key — zero
/// allocation per insert/get/lookup.
///
/// Requires moduli at construction (the torus dimensions).
/// Coordinate validation: each coord[i] must be < moduli[i].
/// Panics if product of moduli exceeds u64 host encoding capacity.
pub struct SparseMap<V> {
    entries: HashMap<u64, V>,
    moduli: Vec<TritInt>,
    strides: Vec<u64>,
}

impl<V> SparseMap<V> {
    pub fn new(moduli: Vec<TritInt>) -> Self {
        let mut strides = Vec::with_capacity(moduli.len());
        let mut stride: u64 = 1;
        for m in &moduli {
            strides.push(stride);
            stride = stride.checked_mul(m.to_decimal())
                .expect("product of moduli exceeds u64 host encoding capacity");
        }
        SparseMap { entries: HashMap::new(), moduli, strides }
    }

    fn encode(&self, coord: &[TritInt]) -> u64 {
        assert_eq!(coord.len(), self.moduli.len(),
            "coordinate dimension {} != map dimension {}", coord.len(), self.moduli.len());
        let mut key: u64 = 0;
        for (i, c) in coord.iter().enumerate() {
            assert!(*c < self.moduli[i], "coord[{}] exceeds modulus", i);
            key += c.to_decimal() * self.strides[i];
        }
        key
    }

    fn decode(&self, mut key: u64) -> Vec<TritInt> {
        self.moduli.iter().map(|m| {
            let m_val = m.to_decimal();
            let c = key % m_val;
            key /= m_val;
            TritInt::from_u64(c)
        }).collect()
    }

    pub fn insert(&mut self, coord: &[TritInt], value: V) -> Option<V> {
        let key = self.encode(coord);
        self.entries.insert(key, value)
    }
    pub fn get(&self, coord: &[TritInt]) -> Option<&V> {
        let key = self.encode(coord);
        self.entries.get(&key)
    }
    pub fn get_mut(&mut self, coord: &[TritInt]) -> Option<&mut V> {
        let key = self.encode(coord);
        self.entries.get_mut(&key)
    }
    pub fn remove(&mut self, coord: &[TritInt]) -> Option<V> {
        let key = self.encode(coord);
        self.entries.remove(&key)
    }
    pub fn contains(&self, coord: &[TritInt]) -> bool {
        let key = self.encode(coord);
        self.entries.contains_key(&key)
    }
    pub fn len(&self) -> usize { self.entries.len() }
    pub fn is_empty(&self) -> bool { self.entries.is_empty() }
    pub fn iter(&self) -> impl Iterator<Item = (Vec<TritInt>, &V)> + '_ {
        self.entries.iter().map(|(&k, v)| (self.decode(k), v))
    }
    pub fn coords(&self) -> impl Iterator<Item = Vec<TritInt>> + '_ {
        self.entries.keys().map(|&k| self.decode(k))
    }
    pub fn clear(&mut self) { self.entries.clear(); }
    pub fn dimensions(&self) -> usize { self.moduli.len() }
    pub fn moduli(&self) -> &[TritInt] { &self.moduli }
}
```

### ZStack — layered sparse maps:

```rust
/// Z-stack: layered sparse maps at different depths/resolutions.
/// Each layer is a SparseMap with its own moduli. Deeper layers
/// correspond to higher-depth repunit decompositions.
pub struct ZStack<V> {
    layers: Vec<SparseMap<V>>,
}

impl<V> ZStack<V> {
    pub fn new() -> Self { ZStack { layers: Vec::new() } }
    pub fn push_layer(&mut self, layer: SparseMap<V>) { self.layers.push(layer); }
    pub fn layer(&self, index: usize) -> Option<&SparseMap<V>> { self.layers.get(index) }
    pub fn layer_mut(&mut self, index: usize) -> Option<&mut SparseMap<V>> { self.layers.get_mut(index) }
    pub fn depth(&self) -> usize { self.layers.len() }
}
```

```rust
/// Rep D trit → UNIFORM k-dimensional torus step vector.
/// Returns Rep B values (0, 1, or 2). Callers convert to TritInt at their level.
///
/// All dimensions receive the same step value.
/// For per-dimension vectors with different coprime generators,
/// construct manually with `coprime::is_coprime` validation.
///
/// Caveat: step=2 (Omega) is only coprime to odd moduli.
/// Step=0 (Zero) produces no movement — stationary coordinates only.
pub fn to_step_vector(d: AlgebraicTrit, k: usize) -> Vec<u8> {
    let step = rep_d_to_b(d);
    vec![step; k]
}

/// Batch convert Rep A trits to Rep B.
pub fn batch_a_to_b(trits: &[i8]) -> Vec<u8> {
    trits.iter().map(|&a| rep_a_to_b(a)).collect()
}

/// Batch convert Rep B trits to Rep A.
pub fn batch_b_to_a(trits: &[u8]) -> Vec<i8> {
    trits.iter().map(|&b| rep_b_to_a(b)).collect()
}
```
