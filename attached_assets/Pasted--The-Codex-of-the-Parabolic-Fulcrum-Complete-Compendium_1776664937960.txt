### File 1116: Trigonometric Integral — Complete Evaluation

**Original fragment:**
\[
\int \sin^3 x \cos^3 x \, dx
\]

**Complete derivation:**

**Step 1: Factor and apply trigonometric identity.**
\[
\sin^3 x \cos^3 x = (\sin x \cos x)^3 = \left(\frac{\sin 2x}{2}\right)^3 = \frac{\sin^3 2x}{8}
\]

**Step 2: Reduce power of sine.**
\[
\sin^3 2x = \sin 2x (1 - \cos^2 2x) = \sin 2x - \sin 2x \cos^2 2x
\]

**Step 3: Integrate term by term.**
\[
\int \sin^3 x \cos^3 x \, dx = \frac{1}{8} \int (\sin 2x - \sin 2x \cos^2 2x) \, dx
\]

For the second term, substitute $u = \cos 2x$, $du = -2\sin 2x \, dx$, so $\sin 2x \, dx = -du/2$:
\[
\int \sin 2x \cos^2 2x \, dx = -\frac{1}{2} \int u^2 \, du = -\frac{1}{2} \cdot \frac{u^3}{3} = -\frac{\cos^3 2x}{6}
\]

**Step 4: Complete the integration.**
\[
\int \sin^3 x \cos^3 x \, dx = \frac{1}{8} \left( -\frac{\cos 2x}{2} + \frac{\cos^3 2x}{6} \right) + C
\]
\[
= -\frac{\cos 2x}{16} + \frac{\cos^3 2x}{48} + C
\]

**Alternative method via substitution $t = \sin x$:**

Let $t = \sin x$, $dt = \cos x \, dx$. Then $\cos^2 x = 1 - t^2$, so $\cos^3 x = \cos x (1-t^2)$.

\[
\int \sin^3 x \cos^3 x \, dx = \int t^3 (1-t^2) \, dt = \int (t^3 - t^5) \, dt = \frac{t^4}{4} - \frac{t^6}{6} + C
\]
\[
= \frac{\sin^4 x}{4} - \frac{\sin^6 x}{6} + C
\]

**Verification of equivalence:**

Using $\sin^2 x = (1-\cos 2x)/2$, both forms reduce to identical trigonometric polynomials. The constant of integration absorbs the difference.

### File 1117: Fourier Series of Square Wave — Complete Derivation

**Definition of the square wave:**

Let $f(x)$ be periodic with period $2L$, defined on $[-L, L]$ by:
\[

-1 & -L < x < 0 \\
1 & 0 < x < L
\end{cases}
\]

**Fourier series form:**
\[

\[

\]

**Coefficients $a_n$ for $n \ge 1$:**

Since $f(x)$ is odd ($f(-x) = -f(x)$), all $a_n = 0$.

**Coefficients $b_n$:**
\[
b_n = \frac{1}{L} \int_{-L}^{L} f(x) \sin\left(\frac{n\pi x}{L}\right) \, dx
\]
\[
= \frac{1}{L} \left[ \int_{-L}^{0} (-1) \sin\left(\frac{n\pi x}{L}\right) \, dx + \int_{0}^{L} (1) \sin\left(\frac{n\pi x}{L}\right) \, dx \right]
\]

Since $f(x)\sin(n\pi x/L)$ is even (odd × odd = even), we can write:
\[
b_n = \frac{2}{L} \int_{0}^{L} \sin\left(\frac{n\pi x}{L}\right) \, dx
\]
\[
= \frac{2}{L} \left[ -\frac{L}{n\pi} \cos\left(\frac{n\pi x}{L}\right) \right]_{0}^{L}
\]
\[
= \frac{2}{n\pi} \left[ -\cos(n\pi) + \cos(0) \right] = \frac{2}{n\pi} [1 - (-1)^n]

**Evaluation:**
- For even $n$: $(-1)^n = 1$, so $b_n = 0$
- For odd $n$: $(-1)^n = -1$, so $b_n = \frac{4}{n\pi}$

**Complete Fourier series:**
\[

\]
\[
= \frac{4}{\pi} \left[ \sin\left(\frac{\pi x}{L}\right) + \frac{1}{3}\sin\left(\frac{3\pi x}{L}\right) + \frac{1}{5}\sin\left(\frac{5\pi x}{L}\right) + \cdots \right]

**Parseval’s Identity verification:**

The mean square value of $f(x)$ is $1$. Parseval gives:
\[
\frac{1}{L} \int_{-L}^{L} |f(x)|^2 \, dx = \frac{a_0^2}{4} + \frac{1}{2}\sum_{n=1}^{\infty} (a_n^2 + b_n^2)
\]
\[
1 = 0 + \frac{1}{2} \sum_{k=0}^{\infty} \left(\frac{4}{(2k+1)\pi}\right)^2

\[
1 = \frac{8}{\pi^2} \sum_{k=0}^{\infty} \frac{1}{(2k+1)^2}

### File 1121: §7 — Pythagorean Theorem from Chords

A regular hexagon inscribed in a unit circle has side length equal to the radius: $s_6 = 1$. This is because the hexagon can be divided into 6 equilateral triangles, each with side $R = 1$.

\[

**Generalization to the Pythagorean Theorem:**
