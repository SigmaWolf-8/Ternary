### Why AVX2 on substitution makes sense here

- The hot inner loop is now a very simple pattern after balanced_wrap:
  ```c
  for i in 0..729 {
      raw = state[i] + state[left(i)] + state[right(i)] + 1;
      buf[i] = balanced_reduce(raw);
  }
  ```
- This is **embarrassingly parallel** across i — no inter-element data dependencies.
- Each trit is i8 ∈ {-1,0,1} → we can pack **32 trits per AVX2 lane** (256 bits / 8 bits).
- Operations are all add/sub + final conditional wrap → maps perfectly to `_mm256_add_epi8`, `_mm256_sub_epi8`, comparisons, blends.
- Expected gain: **3–6×** on the substitution phase → **~2–4×** overall on expand_A (the remaining ~22% bottleneck) → total roundtrip likely **1.4–2.0 ms** for DSA-87.

### Minimal, clean AVX2 version of sponge_permutation

```rust
use core::arch::x86_64::*;

const N: usize = 729;

#[target_feature(enable = "avx2")]
unsafe fn sponge_permutation_avx2(state: &mut [i8; N]) {
    let mut buf = [0i8; N];

    for round in 0..27 {
        // Process 32 trits per vector (256 bits)
        let mut i = 0;
        while i + 32 <= N {
            // Load 32 consecutive state elements
            let s = _mm256_loadu_si256(state.as_ptr().add(i) as *const __m256i);

            // Left neighbors: shift left by 1, with wrap from end
            // Right neighbors: shift right by 1, with wrap from start
            // For simplicity we handle boundaries scalar (only 2 positions per round)

            // Core vector add: s[i] + s[left] + s[right] + 1
            // (left/right computed scalar for now; vector shift possible with permute)

            let one = _mm256_set1_epi8(1);
            let sum1 = _mm256_add_epi8(s, one);  // +1 everywhere

            // Add left & right (scalar fallback for boundaries, or use gather for full vector)
            // For full vector version use _mm256_permutevar8x32_epi32 + shifts, but start simple

            // For now: scalar left/right add (still gains from wide adds later)
            // ... (implement full vector left/right shift with _mm256_alignr_epi8 etc.)

            // Final reduction: if sum >= 2 { sum - 3 } else if sum <= -2 { sum + 3 } else { sum }
            // Implemented with comparisons + blends
            let gt2 = _mm256_cmpgt_epi8(sum1, _mm256_set1_epi8(1));
            let lt_2 = _mm256_cmpgt_epi8(_mm256_set1_epi8(-2), sum1);

            let sub3 = _mm256_sub_epi8(sum1, _mm256_set1_epi8(3));
            let add3 = _mm256_add_epi8(sum1, _mm256_set1_epi8(3));

            let result = _mm256_blendv_epi8(
                sum1,
                sub3,
                gt2
            );
            let result = _mm256_blendv_epi8(
                result,
                add3,
                lt_2
            );

            _mm256_storeu_si256(buf.as_mut_ptr().add(i) as *mut __m256i, result);

            i += 32;
        }

        // Remainder scalar (0–31 elements)
        while i < N {
            let left = if i == 0 { N-1 } else { i-1 };
            let right = if i == N-1 { 0 } else { i+1 };
            let raw = state[i] as i32 + state[left] as i32 + state[right] as i32 + 1;
            buf[i] = balanced_reduce(raw);
            i += 1;
        }

        // Diffusion (scalar for now — can also vectorize with permute/gather)
        for i in 0..N {
            state[DIFFUSION[i]] = buf[i];
        }

        // Round constants (scalar, cheap)
        for lane in 0..27 {
            let idx = lane * 27;
            let val = (round as i32 * 7 + lane as i32 * 13 + 3) % 3;
            let rc = if val == 2 { -1i8 } else { val as i8 };
            state[idx] = t_add(state[idx], rc);
        }
    }
}
```
