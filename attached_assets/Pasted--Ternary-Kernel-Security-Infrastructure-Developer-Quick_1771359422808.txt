## Core Architecture

### 4 Backend Services

| Service | Responsibility | Key Tables |
|---------|-----------------|-----------|
| **Audit Service** | Security event logging & severity aggregation | `security_audit_log` |
| **HPTP Service** | Timing protocol health monitoring | `hptp_anomaly_events` |
| **Threat Service** | Risk modeling & mitigation tracking | `threat_model_entries` |
| **Implementation Service** | Component progress tracking | `implementation_status` |

### 4 Database Tables

```
security_audit_log        ← All security events (immutable, append-only)
hptp_anomaly_events       ← Timing anomalies with fallback chain state
threat_model_entries      ← Threat registry with risk matrices
implementation_status     ← 50+ component progress tracking
```

## Integration Examples

### Integrate with Kernel (C Code)

**When**: Crypto subsystem detects anomaly  
**How**: Call REST endpoint from kernel module

```c
#include <curl/curl.h>

void report_crypto_anomaly(const char *anomaly_type, double variance) {
  CURL *curl = curl_easy_init();
  
  const char *json_payload = "{\"severity\":\"critical\","
    "\"category\":\"crypto\","
    "\"event_type\":\"aes_timing_variance\","
    "\"actor\":\"kernel/crypto/aes_256_gcm\","
    "\"description\":\"Timing jitter exceeds threshold\","
    "\"evidence\":{\"variance_observed\":%.2f}}";
  
  curl_easy_setopt(curl, CURLOPT_URL, 
    "https://security.capomastro.dev/api/security/v1/audit/events");
  curl_easy_setopt(curl, CURLOPT_POSTFIELDS, json_payload);
  curl_easy_setopt(curl, CURLOPT_HTTPAUTH, CURLAUTH_BEARER);
  curl_easy_setopt(curl, CURLOPT_XOAUTH2_BEARER, bearer_token);
  
  curl_easy_perform(curl);
  curl_easy_cleanup(curl);
}
```

### Integrate with Dashboard (JavaScript/React)

**When**: Dashboard renders security status  
**How**: Query API endpoints and display results

```javascript
// React component: SecurityDashboard.jsx
import { useEffect, useState } from 'react';

export function SecurityDashboard() {
  const [unresolved, setUnresolved] = useState([]);
  const [hptp, setHptp] = useState({});
  
  useEffect(() => {
    // Fetch unresolved critical/high events
    fetch('/api/security/v1/audit/events/unresolved?severity=critical,high', {
      headers: { 'Authorization': `Bearer ${token}` }
    })
      .then(r => r.json())
      .then(data => setUnresolved(data));
    
    // Fetch HPTP status
    fetch('/api/security/v1/hptp/status', {
      headers: { 'Authorization': `Bearer ${token}` }
    })
      .then(r => r.json())
      .then(data => setHptp(data));
  }, []);
  
  return (
    <div>
      <h2>Critical Events: {unresolved.length}</h2>
      <div>HPTP Active Tier: {hptp.active_tier}</div>
    </div>
  );
}
```

### Integrate with Monitoring (Python)

**When**: Prometheus scraper collects metrics  
**How**: Poll API and export metrics

```python
# prometheus_exporter.py
import requests
import time
from prometheus_client import Gauge, start_http_server

# Define metrics
critical_events = Gauge('security_critical_events', 'Critical unresolved events')
hptp_active_tier = Gauge('hptp_active_tier', 'HPTP fallback tier', ['tier'])

def collect_metrics():
    headers = {'Authorization': f'Bearer {BEARER_TOKEN}'}
    
    # Get critical events
    resp = requests.get(
        'https://security.capomastro.dev/api/security/v1/audit/summary?hours=1',
        headers=headers
    )
    critical_events.set(resp.json()['critical_count'])
    
    # Get HPTP status
    resp = requests.get(
        'https://security.capomastro.dev/api/security/v1/hptp/status',
        headers=headers
    )
    tier = resp.json()['active_tier']
    hptp_active_tier.labels(tier=tier).set(1)

if __name__ == '__main__':
    start_http_server(8000)  # Prometheus scrapes on :8000/metrics
    while True:
        collect_metrics()
        time.sleep(30)
```

## Troubleshooting

### Issue: 401 Unauthorized

**Problem**: API returns `{"error":"Unauthorized"}`

**Solution**:
```bash
# 1. Check token is valid
curl -X POST https://security.capomastro.dev/auth/verify \
  -H "Authorization: Bearer $TOKEN"

# 2. Refresh token if expired
curl -X POST https://security.capomastro.dev/auth/refresh \
  -H "Authorization: Bearer $TOKEN"

# 3. Verify Authorization header format
# Correct: "Authorization: Bearer <token>"
# Wrong: "Authorization: <token>"
```

### Issue: 400 Validation Error

**Problem**: API returns validation error details

**Solution**:
```bash
# Check the validation error details
curl -X POST https://security.capomastro.dev/api/security/v1/audit/events \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"severity":"invalid"}' | jq .details

# Output shows: [{ field: "severity", message: "Invalid enum value" }]
# Fix: Use valid enum: "info", "warning", "high", "critical"
```

### Issue: 5xx Server Error

**Problem**: API returns 500 Internal Server Error

**Solution**:
```bash
# 1. Check service status
curl https://security.capomastro.dev/health

# 2. Check database connectivity
curl https://security.capomastro.dev/health/db

# 3. View server logs
kubectl logs -f deployment/security-api -n capomastro

# 4. Escalate to DevOps if persistent
```
