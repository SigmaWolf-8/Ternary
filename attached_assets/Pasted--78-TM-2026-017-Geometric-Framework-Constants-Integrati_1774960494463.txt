#78 - TM-2026-017 Geometric Framework Constants Integration
What & Why
TM-2026-017 v5.0 (Extended Geometric Framework — "From the Axiom π = 14") is now saved as docs/monographs/TM-2026-017-Extended-Geometric-Framework.md. A cross-reference against the existing codebase identified 10 constant groups from the monograph that are NOT yet represented in shared/constants.ts or the Rust kernel modules. This task integrates them so the single-source-of-truth constants file fully reflects TM-2026-017 alongside the already-integrated TM-2026-025.

Done looks like
shared/constants.ts has a new GEOMETRIC_FRAMEWORK (or extension to PLENUM_SQUARE) block containing all missing constants from TM-2026-017 v5.0.
src/kernel/src/browser/color.rs has any needed Rust-side constant additions (superhub zone data, node census).
A Vitest test suite (tests/geometric-framework.test.ts) validates the key identities from TM-2026-017.
All existing tests still pass.
replit.md updated.
Pushed to GitHub.
Out of scope
Frontend UI pages or visualizations for the geometric framework.
Changes to Bézier interpolation logic in color.rs (already working).
Any changes to deployments/ folder.
Re-deriving constants that already exist (182, 650, 832, 118300, 468, etc. are already present).
